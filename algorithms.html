第1章 线性表 · 1.1 顺序表操作必考模板考场禁用STL考频 ★★★

🎬 对应课程：慕课顺序表 + L3 顺序vs链式对比（PAGE 33-34） ｜ 考试规则见 L0/L26

算法思想：连续存储+位序换算（位序i ↔ 下标i-1）；插入删除靠整体搬移。适用场景：随机访问频繁、按值插删少。答题书写步骤：①判参数合法性→②判表满/空→③搬移元素（先想清楚边界）→④赋值+length增减→⑤返回bool；删除值用引用e带回。

#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int length;
} SqList;

void InitList(SqList &L) { L.length = 0; }

// 插入：第i个位序插入e（1 ≤ i ≤ length+1），平均移动n/2
bool ListInsert(SqList &L, int i, int e) {
    if (i < 1 || i > L.length + 1) return false;    // 位序不合法
    if (L.length >= MaxSize) return false;          // 表满
    for (int j = L.length; j >= i; j--)             // 第i个及以后整体后移
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;                              // 位序i → 下标i-1
    L.length++;
    return true;
}

// 删除：删第i个元素，e带回，平均移动(n-1)/2
bool ListDelete(SqList &L, int i, int &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    for (int j = i; j < L.length; j++)
        L.data[j - 1] = L.data[j];
    L.length--;
    return true;
}

// 按值查找：返回位序，0表示不存在
int LocateElem(SqList L, int e) {
    for (int i = 0; i < L.length; i++)
        if (L.data[i] == e) return i + 1;
    return 0;
}
插入/删除 O(n)按位序取 O(1)按值查 O(n)空间 O(MaxSize)
STL替代标注：笔试禁用vector代替顺序表作答；机试可直接 v.insert(v.begin()+i-1, e) / v.erase(v.begin()+i-1)。高频易错：搬移边界（j≥i 还是 j>i）必须推演；平均移动次数：插入n/2、删除(n-1)/2。
【例1·基础题】

长度为n的顺序表等概率插入，平均移动多少元素？删除呢？

查看解析

插入n/2，删除(n-1)/2。插入有n+1个合法位置（移动n…0），期望n/2；删除n个位置（移动n-1…0），期望(n-1)/2。

【例2·408真题风格题】

设计算法将顺序表中所有值在[s,t]（s<t）之间的元素删除，要求O(n)、O(1)，不合理返回false。

查看解析
bool DelRange(SqList &L, int s, int t) {
    if (s >= t || L.length == 0) return false;
    int k = 0;                              // k：保留区下一个位置
    for (int i = 0; i < L.length; i++)
        if (L.data[i] < s || L.data[i] > t)
            L.data[k++] = L.data[i];
    L.length = k;
    return true;
}

考点：读写双指针一趟完成（对照LC283移动零）。逐个删是O(n²)——"时间尽可能高效"提示双指针。

第1章 线性表 · 1.2 链表操作必考模板考场禁用STL考频 ★★★

🎬 对应课程：L3 全讲（Find/Search/Insert/Delete + 哨位结点） ｜ 考试规则见 L0/L26

算法思想：指针维护逻辑次序；头插建表逆序、尾插建表保序；插入删除只改指针。适用场景：插删频繁、长度未知、就地操作题（逆置/合并/找中点）。答题书写步骤：①声明"带头结点单链表"→②工作指针p、前驱pre、暂存q分工→③画图确认语句次序→④返回头结点或bool。

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

// 头插法建表：输入顺序与链表顺序相反（高频考点）
void CreateList_Head(LinkList &L, int a[], int n) {
    L = (LNode*)malloc(sizeof(LNode));      // 头结点
    L->next = NULL;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i];
        s->next = L->next;                  // 插到表头
        L->next = s;
    }
}

// 尾插法建表：需尾指针r，输入顺序=链表顺序
void CreateList_Tail(LinkList &L, int a[], int n) {
    L = (LNode*)malloc(sizeof(LNode));
    LNode *r = L;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i]; r->next = s; r = s;
    }
    r->next = NULL;
}

LNode* GetElem(LinkList L, int i) {         // 按位序查找，越界返回NULL
    if (i == 0) return L;
    LNode *p = L->next;
    for (int j = 1; p && j < i; j++) p = p->next;
    return p;
}

bool InsertNext(LNode *p, int e) {          // 后插 O(1)
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = e; s->next = p->next; p->next = s;
    return true;
}

bool InsertPrior(LNode *p, int e) {         // 前插"偷天换日"：先后插再换数据域
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->next = p->next; p->next = s;
    s->data = p->data; p->data = e;
    return true;
}

// 删除结点p的后继：暂存q防断链，先接再删
bool DeleteNext(LNode *p) {
    if (!p->next) return false;
    LNode *q = p->next;
    p->next = q->next;
    free(q);
    return true;
}
void Reverse(LinkList &L) {                 // 就地逆置（头插重建）
    LNode *p = L->next, *q;
    L->next = NULL;
    while (p) {
        q = p->next;
        p->next = L->next;
        L->next = p;
        p = q;
    }
}
查找/定位 O(n)已知位置插删 O(1)空间 每结点多1指针
STL替代标注：笔试禁用std::list；机试可用。高频易错：双链表插入四步"先接后断"（s->next=p->next; s->prior=p; p->next->prior=s; p->next=s;）次序不能乱；逆置必须暂存q防断链。
【例1·基础题】

头插法依次插入1,2,3，链表次序是？尾插法呢？

查看解析

头插：3→2→1（与输入相反）；尾插：1→2→3（保序）。"头插逆序、尾插保序"必背。

【例2·408真题风格题】

两个递增单链表A、B归并为递增链表C，利用原结点、不申请新空间。

查看解析
void MergeList(LinkList &La, LinkList &Lb, LinkList &Lc) {
    LNode *pa = La->next, *pb = Lb->next;
    Lc = La; LNode *r = Lc;                 // 借La头结点，尾插保递增
    while (pa && pb) {
        if (pa->data <= pb->data) { r->next = pa; r = pa; pa = pa->next; }
        else                      { r->next = pb; r = pb; pb = pb->next; }
    }
    r->next = pa ? pa : pb;                 // 整段接管剩余
    free(Lb);
}

O(m+n)/O(1)，即归并排序Merge的链表版（对应LC21，第七部分）。

第1章 线性表 · 1.3 双指针算法必考模板考频 ★★★

🎬 对应课程：L3 双指针技巧（PAGE 50-74） ｜ 考试规则见 L0/L26

算法思想：用两个同向/相向指针把O(n²)暴力压成O(n)：同向=读写指针（原地删/划分），相向=首尾指针（有序数组两数和）。适用场景：原地删除、划分、有序配对、区间收缩。答题书写步骤：①明确两个指针含义→②写清移动条件（谁动、何时动）→③证明不重不漏。

// ① 读写指针：原地删除所有等于x的元素，返回新长度
int RemoveAll(int a[], int n, int x) {
    int k = 0;
    for (int i = 0; i < n; i++)
        if (a[i] != x) a[k++] = a[i];
    return k;
}

// ② 首尾指针：非降序a[]中找和为target的两元素下标
bool twoSum(int a[], int n, int target, int &i, int &j) {
    int l = 0, r = n - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == target)     { i = l; j = r; return true; }
        else if (s < target) l++;
        else                 r--;
    }
    return false;
}

// ③ 原地划分（快排Partition思想）：以a[0]为基准，小的在左大的在右
int Partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;
        a[high] = a[low];
    }
    a[low] = pivot;
    return low;
}
三种模板 时间O(n)空间 O(1)
STL替代标注：双指针没有STL可替代——是必考思想本身；std::remove思想同模板①。对应真题：LC283移动零、LC11盛水、LC15三数之和（第七部分）。
【例1·基础题】

有序数组{1,3,5,7,9}找和为10的两个数。

查看解析

l=0(1),r=4(9)：和10命中 → 下标0和4。口诀"和小l++、和大r--"。

【例2·408真题风格题】

递增顺序表原地删除重复元素（保留一个），O(n)/O(1)。

查看解析
int RemoveDup(int a[], int n) {
    if (n == 0) return 0;
    int k = 0;
    for (int i = 1; i < n; i++)
        if (a[i] != a[k]) a[++k] = a[i];
    return k + 1;
}

利用有序性：i扫到与保留区末尾不同才保留（对照unique的思想，第六部分·实战e1）。

第1章 线性表 · 1.4 快慢指针必考模板考频 ★★

🎬 对应课程：L3 快慢指针（倒数第k/中点/判环/回文/重排） ｜ 考试规则见 L0/L26

算法思想：同向双指针的链表特化——慢针一次1步、快针一次k步：k=2找中点/判环（Floyd判圈）。适用场景：中点、判环、倒数第k个、回文链表。答题书写步骤：①初始化都指向首元结点→②循环条件 fast && fast->next→③返回慢针。

// ① 找中间结点：偶数个时返回后一个中点
LNode* Mid(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

// ② 判环：快针追上慢针则有环
bool HasCycle(LNode *head) {
    LNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

// ③ 倒数第k个：fast先走k步，再同步走
LNode* FindKthFromEnd(LinkList L, int k) {
    LNode *fast = L->next, *slow = L->next;
    for (int i = 0; i < k; i++) {
        if (!fast) return NULL;             // k超长
        fast = fast->next;
    }
    while (fast) { fast = fast->next; slow = slow->next; }
    return slow;
}
时间 O(n)空间 O(1)
STL替代标注：无STL可替代，指针思想本身即考点。对应真题：LC141/142/19/234（第七部分链表模块）。
【例1·基础题】

1→2→3→4→5，Mid返回哪个结点？若是1→2→3→4呢？

查看解析

5个结点返回3；4个结点返回3（偶数个返回后一个中点）。若要前一个中点，循环条件改 fast->next && fast->next->next。

【例2·408真题风格题】

判断带头结点单链表是否回文，要求O(n)、O(1)。

查看解析

三步：①快慢指针找中点（1.4模板①）；②就地逆置后半段（1.2 Reverse）；③前半段与逆置段逐结点比较，最后（可选）再逆回去还原。

O(n)/O(1)——即LC234标准解法（第七部分），三问合一的典型408大题。

第2章 栈与队列 · 2.1 栈的模拟与实现必考模板考场禁用STL考频 ★★★

🎬 对应课程：L4 栈（进制转换/括号匹配/表达式求值/栈混洗） ｜ 考试规则见 L0/L26

算法思想：LIFO，顺序栈用top指针管理栈顶。适用场景：括号匹配、表达式求值、递归转非递归、DFS。答题书写步骤：①先声明top约定（top指向栈顶元素、空栈-1，另一种约定指向下一空位——题目给哪种就用哪种）→②进出栈先判满/空→③"先移指针再存/先取再移"。

#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;                                // 栈顶指针：空栈为-1
} SqStack;

void InitStack(SqStack &S) { S.top = -1; }
bool StackEmpty(SqStack S) { return S.top == -1; }

bool Push(SqStack &S, int x) {
    if (S.top == MaxSize - 1) return false; // 栈满上溢
    S.data[++S.top] = x;                    // 先移指针再存入
    return true;
}
bool Pop(SqStack &S, int &x) {
    if (S.top == -1) return false;          // 栈空下溢
    x = S.data[S.top--];                    // 先取值再移指针
    return true;
}
bool GetTop(SqStack S, int &x) {
    if (S.top == -1) return false;
    x = S.data[S.top];
    return true;
}

// 共享栈：两栈顶相向，栈满条件 top1+1 == top2（选择题常客）
typedef struct { int data[MaxSize]; int top1, top2; } SharedStack;
void InitShared(SharedStack &S) { S.top1 = -1; S.top2 = MaxSize; }
bool PushShared(SharedStack &S, int which, int x) {
    if (S.top1 + 1 == S.top2) return false; // 相遇即满
    if (which == 0) S.data[++S.top1] = x;
    else            S.data[--S.top2] = x;
    return true;
}
入栈/出栈/取栈顶 O(1)空间 O(n)
STL替代标注：笔试禁用stack（题目考的就是栈结构）；机试直接 stack<int>。高频易错：①链栈=头插单链表，无栈满（判断题）；②n个不同元素出栈序列共 Catalan数 C(2n,n)/(n+1) 种；③共享栈满条件 top1+1==top2。
【例1·基础题】

top指向栈顶元素（初始-1）与指向下一空位（初始0）两种约定下，Push分别怎么写？

查看解析

约定一：S.data[++S.top] = x;（先加后存）；约定二：S.data[S.top++] = x;（先存后加）。判满条件分别为 top==MaxSize-1 与 top==MaxSize。读题先看约定！

【例2·408真题风格选择题】

入栈1,2,3,4，不可能的出栈序列：A.3,4,2,1　B.1,4,3,2　C.4,3,1,2　D.2,3,4,1

查看解析

C。弹4,3后栈底到顶为1,2，栈顶是2而目标为1——不合法。A/B/D模拟均可行。

第2章 栈与队列 · 2.2 队列的模拟与实现必考模板考场禁用STL考频 ★★★

🎬 对应课程：L4 循环队列两方案（PAGE 151-153 考研真题） ｜ 考试规则见 L0/L26

算法思想：FIFO；数组取模实现逻辑循环。适用场景：BFS、层序遍历、缓冲区。答题书写步骤：①写明判空判满方案（三选一并贯彻全篇）→②入队"先存后移"、出队"先取后移"→③指针都取模。

#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;                        // rear指向队尾后一位置
} SqQueue;

void InitQueue(SqQueue &Q) { Q.front = Q.rear = 0; }
bool QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }
bool QueueFull(SqQueue Q)  { return (Q.rear + 1) % MaxSize == Q.front; }

bool EnQueue(SqQueue &Q, int x) {
    if (QueueFull(Q)) return false;
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
bool DeQueue(SqQueue &Q, int &x) {
    if (QueueEmpty(Q)) return false;
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
// 元素个数：(rear - front + MaxSize) % MaxSize

牺牲一个单元front == rear(rear+1)%MaxSize == front(rear-front+MaxSize)%MaxSize
增设sizesize == 0size == MaxSizesize
增设tagtag==0 且 front==reartag==1 且 front==rear—
入队/出队 O(1)可用容量 牺牲方案MaxSize-1
STL替代标注：笔试禁用queue；机试直接用。高频易错：元素个数公式必须默写；链队front指头结点、rear指尾。
【例1·基础题】

data[0..59]，front=30、rear=15（牺牲单元方案），队列元素个数？

查看解析

(15-30+60)%60 = 45。rear绕圈到front前面，公式加MaxSize拉回正数再取模。

【例2·408真题风格选择题】

循环队列用tag区分队空队满，最多存多少元素？front==rear且tag==1的含义？

查看解析

第2章 栈与队列 · 2.3 单调栈必考模板考频 ★★

🎬 对应课程：L18 堆结构延伸 + L4 栈应用（接雨水） ｜ 考试规则见 L0/L26

算法思想：栈内下标对应值保持单调；新元素"清算"栈中破坏单调者——出栈即得答案。每元素至多进出各一次→O(n)。适用场景：下一个更大元素、每日温度、柱状图最大矩形、接雨水。答题书写步骤：①栈存下标→②while清算→③入栈→④收尾清算剩余。

void nextGreater(int a[], int n, int res[]) {
    int stk[MaxSize], top = -1;             // 栈存下标，值严格递减
    for (int i = 0; i < n; i++) {
        while (top >= 0 && a[i] > a[stk[top]])
            res[stk[top--]] = i;            // 出栈：a[i]是其右侧首个更大值
        stk[++top] = i;
    }
    while (top >= 0) res[stk[top--]] = -1;  // 无更大值
}
时间 O(n)空间 O(n)

void slidingMax(int a[], int n, int k, int res[]) {
    int q[MaxSize], front = 0, rear = 0;    // q存下标，值递减
    int cnt = 0;
    for (int i = 0; i < n; i++) {
        while (rear > front && a[q[rear - 1]] <= a[i]) rear--;  // ①队尾出
        q[rear++] = i;                                          // ②入队尾
        if (q[front] <= i - k) front++;                         // ③队头过期
        if (i >= k - 1) res[cnt++] = a[q[front]];               // ④取答案
    }
}

void InOrder2(BiTree T) {
    BiTNode *stk[MaxSize]; int top = -1;
    BiTNode *p = T;
    while (p || top >= 0) {
        if (p) { stk[++top] = p; p = p->lchild; }      // ①沿左链入栈
        else {
            p = stk[top--];                             // ②弹栈访问
            visit(p);
            p = p->rchild;                              // ③转右子树
        }
    }
}
void PreOrder2(BiTree T) {
    BiTNode *stk[MaxSize]; int top = -1;
    BiTNode *p = T;
    while (p || top >= 0) {
        if (p) {
            visit(p);                        // 与中序唯一区别：入栈前访问
            stk[++top] = p;
            p = p->lchild;
        } else {
            p = stk[top--];
            p = p->rchild;
        }
    }
}
void PostOrder2(BiTree T) {
    BiTNode *stk[MaxSize]; int top = -1;
    BiTNode *p = T, *last = NULL;            // last：上一个访问的结点
    while (p || top >= 0) {
        if (p) { stk[++top] = p; p = p->lchild; }
        else {
            p = stk[top];                                // 看栈顶不弹
            if (p->rchild && p->rchild != last)
                p = p->rchild;                           // 右子树未访问
            else {
                visit(p); last = p; top--; p = NULL;     // 访问并回退
            }
        }
    }
}
void LevelOrder(BiTree T) {
    BiTNode *que[MaxSize]; int front = 0, rear = 0;
    if (T) que[rear++] = T;
    while (front < rear) {
        BiTNode *p = que[front++];
        visit(p);
        if (p->lchild) que[rear++] = p->lchild;
        if (p->rchild) que[rear++] = p->rchild;
    }
}

typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;                          // 0孩子 1线索
} ThreadNode, *ThreadTree;

void InThread(ThreadTree T, ThreadTree &pre) {
    if (!T) return;
    InThread((ThreadTree)T->lchild, pre);
    if (!T->lchild) { T->lchild = pre; T->ltag = 1; }        // 左空：前驱线索
    if (pre && !pre->rchild) { pre->rchild = T; pre->rtag = 1; }  // pre右空：后继线索
    pre = T;
    InThread((ThreadTree)T->rchild, pre);
}
void CreateInThread(ThreadTree T) {
    ThreadTree pre = NULL;
    if (T) { InThread(T, pre); pre->rchild = NULL; pre->rtag = 1; }
}

    while (p->ltag == 0) p = p->lchild;
    return p;
}

    if (p->rtag == 1) return p->rchild;
    return First(p->rchild);
}// 不用栈、不用递归的中序遍历：沿线索链一路 Next
void ThreadInOrder(ThreadNode *T) {
    for (ThreadNode *p = First(T); p; p = Next(p))

}

#define N 100
typedef struct {
    int weight;
    int parent, lchild, rchild;              // -1表示空
} HTNode;

void CreateHuffman(int w[], int n, HTNode ht[]) {
    int m = 2 * n - 1;                       // 总结点数
    for (int i = 0; i < m; i++) {            // 初始化
        ht[i].weight = (i < n) ? w[i] : 0;
        ht[i].parent = ht[i].lchild = ht[i].rchild = -1;
    }
    for (int i = n; i < m; i++) {            // 合并n-1次
        int s1 = -1, s2 = -1;                // s1最小 s2次小
        for (int j = 0; j < i; j++)
            if (ht[j].parent == -1) {        // 只在森林中选
                if (s1 == -1 || ht[j].weight < ht[s1].weight) { s2 = s1; s1 = j; }
                else if (s2 == -1 || ht[j].weight < ht[s2].weight) s2 = j;
            }
        ht[s1].parent = ht[s2].parent = i;
        ht[i].lchild = s1; ht[i].rchild = s2;
        ht[i].weight = ht[s1].weight + ht[s2].weight;
    }
}

算法思想：双亲表示法存集合，Find上溯找根、Union合并两根；路径压缩+按大小合并后近乎O(1)。适用场景：连通分量计数、Kruskal判环、等价类。答题书写步骤：①fa[i]=i初始化→②合并前先找两根、不同才合→③数根即数集合。

int fa[MaxSize];
int sz[MaxSize];                             // sz[root]：集合大小

void Init(int n) {
    for (int i = 0; i < n; i++) { fa[i] = i; sz[i] = 1; }
}
int Find(int x) {                            // 无优化版
    while (fa[x] != x) x = fa[x];
    return x;
}
// 合并两集合：先找两根，不同根才挂接（防自环）
void Union(int x, int y) {
    int rx = Find(x), ry = Find(y);
    if (rx != ry) fa[rx] = ry;
}
int Find2(int x) {                           // 路径压缩：沿途直接挂根
    if (fa[x] != x) fa[x] = Find2(fa[x]);
    return fa[x];
}
void Union2(int x, int y) {                  // 按大小合并
    int rx = Find2(x), ry = Find2(y);
    if (rx == ry) return;
    if (sz[rx] < sz[ry]) { int t = rx; rx = ry; ry = t; }
    fa[ry] = rx;
    sz[rx] += sz[ry];
}

第4章 图 · 4.2 图的BFS与DFS必考模板考场禁用STL考频 ★★★

🎬 对应课程：L13 DFS/BFS 与四大应用（判环三状态） ｜ 考试规则见 L0/L26

算法思想：BFS借队列逐层扩散（无权图即最短路）；DFS借递归/栈一条路走黑。答题书写步骤：①visited[]全初始化false→②BFS：入队即标记→③DFS：访问即标记→④非连通图外层循环补遍历（顺带数连通分量）。

bool visited[MaxVertex];

void BFS(ALGraph G, int v) {                 // 邻接表O(V+E)
    int que[MaxVertex], front = 0, rear = 0;
    visited[v] = true;                       // 入队即标记！
    que[rear++] = v;
    while (front < rear) {
        int u = que[front++];
        visit(u);
        for (ArcNode *p = G.vertices[u].first; p; p = p->next)
            if (!visited[p->adjvex]) {
                visited[p->adjvex] = true;
                que[rear++] = p->adjvex;
            }
    }
}

void DFS(ALGraph G, int v) {                 // 递归DFS
    visited[v] = true;
    visit(v);
    for (ArcNode *p = G.vertices[v].first; p; p = p->next)
        if (!visited[p->adjvex]) DFS(G, p->adjvex);
}

void Traverse(ALGraph G) {                   // 非连通图完整遍历
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    int cnt = 0;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) { cnt++; BFS(G, i); }   // cnt=连通分量数
}

void BFS_Shortest(ALGraph G, int src, int d[]) {   // 无权单源最短路
    for (int i = 0; i < G.vexnum; i++) d[i] = -1;
    int que[MaxVertex], front = 0, rear = 0;
    visited[src] = true; d[src] = 0;
    que[rear++] = src;
    while (front < rear) {
        int u = que[front++];
        for (ArcNode *p = G.vertices[u].first; p; p = p->next)
            if (!visited[p->adjvex]) {
                visited[p->adjvex] = true;
                d[p->adjvex] = d[u] + 1;     // 首次到达即最短（边权全1）
                que[rear++] = p->adjvex;
            }
    }
}

第4章 图 · 4.4 Dijkstra（单源最短路径）必考模板考场禁用STL考频 ★★★

🎬 对应课程：L15 Dijkstra（三步/逐轮表格/pre 输出路径） ｜ 考试规则见 L0/L26

算法思想：贪心——每轮确认一个dist最小且未确认的顶点，再用它松弛邻居；要求边权非负。答题书写步骤：①初始化dist/path/final→②"选点—确认—松弛"三步循环n-1次→③路径沿path逆序还原。

int dist[MaxVertex];                         // 当前最短路径长度
int path[MaxVertex];                         // 前驱顶点

void Dijkstra(MGraph G, int v0) {
    bool final_[MaxVertex];                  // true=已确定
    for (int i = 0; i < G.vexnum; i++) {
        dist[i] = G.Edge[v0][i];
        final_[i] = false;
        path[i] = (G.Edge[v0][i] < INF) ? v0 : -1;
    }
    dist[v0] = 0; final_[v0] = true;
    for (int i = 0; i < G.vexnum - 1; i++) {
        int u = -1, min = INF;
        for (int j = 0; j < G.vexnum; j++)   // ①选未确认dist最小者
            if (!final_[j] && dist[j] < min) { min = dist[j]; u = j; }
        if (u == -1) break;                  // 剩余不可达
        final_[u] = true;                    // ②确认（贪心不可反悔）
        for (int j = 0; j < G.vexnum; j++)   // ③松弛
            if (!final_[j] && dist[u] + G.Edge[u][j] < dist[j]) {
                dist[j] = dist[u] + G.Edge[u][j];
                path[j] = u;
            }
    }
}

第4章 图 · 4.5 Floyd（多源最短路径）考场禁用STL考频 ★★

🎬 对应课程：L15 Floyd（递推矩阵/path 语义 PAGE 89-98） ｜ 考试规则见 L0/L26

算法思想：动态规划——依次允许每个顶点k作中转，dist[i][j]=min(dist[i][j], dist[i][k]+dist[k][j])。可处理负权边（不允许负权回路）。答题书写步骤：①dist初始化为直达、mid=-1→②k-i-j三重循环（k最外层！）→③路径沿mid递归还原。

int dist[MaxVertex][MaxVertex];
int mid[MaxVertex][MaxVertex];

void Floyd(MGraph G) {
    for (int i = 0; i < G.vexnum; i++)
        for (int j = 0; j < G.vexnum; j++) {
            dist[i][j] = G.Edge[i][j];
            mid[i][j] = -1;
        }
    for (int k = 0; k < G.vexnum; k++)       // ①中转点k必须最外层
        for (int i = 0; i < G.vexnum; i++)
            for (int j = 0; j < G.vexnum; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j]) {   // ②借道更短
                    dist[i][j] = dist[i][k] + dist[k][j];
                    mid[i][j] = k;
                }
}

        closest[j] = u0;

    for (int i = 1; i < G.vexnum; i++) {
        int u = -1, min = INF;
        for (int j = 0; j < G.vexnum; j++)   // ①树外选lowcost最小

        if (u == -1) break;

typedef struct { int u, v, w; } Edge;

int fa[MaxVertex];
int Find(int x) { while (fa[x] != x) x = fa[x]; return x; }

void Kruskal(Edge e[], int m, int n) {       // m条边 n个顶点
    for (int i = 0; i < m - 1; i++)          // ①按权升序排序
        for (int j = 0; j < m - 1 - i; j++)
            if (e[j].w > e[j + 1].w) {
                Edge t = e[j]; e[j] = e[j + 1]; e[j + 1] = t;
            }
    for (int i = 0; i < n; i++) fa[i] = i;   // ②初始化
    int cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        int ru = Find(e[i].u), rv = Find(e[i].v);
        if (ru != rv) {                      // ③不同根→不成环
            fa[ru] = rv;
            printf("(%d,%d) w=%d\n", e[i].u, e[i].v, e[i].w);
            cnt++;
        }
    }
    if (cnt < n - 1) printf("图不连通\n");
}

算法思想：AOE网顶点=事件、边=活动（带工期）。关键路径=最长路径=工期下限；关键活动：时间余量l−e=0。答题书写步骤（四步）：①拓扑序求ve（取max）→②逆拓扑序求vl（取min，vl汇=ve汇）→③每条活动<i,j>：e=ve(i)、l=vl(j)−w→④e==l即关键活动。

算法思想：顺序=哨兵从头/尾扫；折半=有序表每次比较淘汰一半。折半前提：有序+顺序存储（链表不能折半）。答题书写步骤：①low/high/mid定义清楚→②循环条件 low<=high→③三分支→④失败返回-1；画判定树辅助。

int SeqSearch(int a[], int n, int key) {     // a[0]作哨兵，返回0表示失败
    a[0] = key;
    int i = n;
    while (a[i] != key) i--;                 // 从尾向头，省越界判断
    return i;
}

int BinSearch(int a[], int n, int key) {     // a[0..n-1]非降序
    int low = 0, high = n - 1;
    while (low <= high) {                    // 闭区间用 <=
        int mid = (low + high) / 2;          // 向下取整
        if (a[mid] == key) return mid;
        else if (a[mid] > key) high = mid - 1;
        else                   low  = mid + 1;
    }
    return -1;
}

第5章 查找 · 5.2 二叉排序树（BST）必考模板考场禁用STL考频 ★★★

🎬 对应课程：L23 BST（删除三情况/退化O(n)） ｜ 考试规则见 L0/L26

算法思想：左<根<右递归成立；中序遍历得递增序列——判断/构造/找前驱后继的万能钥匙。答题书写步骤：①查找沿"小往左大往右"→②插入总是落在叶子→③删除分三情况（叶/单孩子/双子树）。

typedef struct BSTNode {
    int data;
    struct BSTNode *lchild, *rchild;
} BSTNode, *BSTree;

BSTNode* BSTSearch(BSTree T, int key) {      // 非递归查找
    while (T && key != T->data)
        T = (key < T->data) ? T->lchild : T->rchild;
    return T;
}

bool BSTInsert(BSTree &T, int key) {         // 递归插入，总是插成叶子
    if (!T) {
        T = (BSTree)malloc(sizeof(BSTNode));
        T->data = key; T->lchild = T->rchild = NULL;
        return true;
    }
    if (key == T->data) return false;        // 已存在不插
    if (key < T->data) return BSTInsert(T->lchild, key);
    return BSTInsert(T->rchild, key);
}

void BSTDelete(BSTree &T, int key) {         // 删除
    if (!T) return;
    if (key < T->data)      BSTDelete(T->lchild, key);
    else if (key > T->data) BSTDelete(T->rchild, key);
    else {
        if (T->lchild == NULL) { BSTNode *p = T; T = T->rchild; free(p); }
        else if (T->rchild == NULL) { BSTNode *p = T; T = T->lchild; free(p); }
        else {                               // 双子树：用直接前驱顶替
            BSTNode *pre = T->lchild;        // 前驱=左子树最右
            while (pre->rchild) pre = pre->rchild;
            T->data = pre->data;
            BSTDelete(T->lchild, pre->data); // 转化为删前驱
        }
    }
}
平均 O(logn)最坏（有序插入成单支） O(n)
STL替代标注：笔试禁用set/map代替BST作答；机试可以。高频易错：①双子树删除用前驱（左子树最右）或后继（右子树最左）替换后转化为删叶/单孩子；②插入次序不同树形不同——ASL随插入序变化。

#define M 13                                 // 表长（素数）
typedef struct HNode {
    int key;
    struct HNode *next;
} HNode;
HNode *HT[M];                                // 拉链法：桶数组

int Hash(int key) { return key % M; }

void HashInsert(int key) {
    int h = Hash(key);
    HNode *s = (HNode*)malloc(sizeof(HNode));
    s->key = key;
    s->next = HT[h];                         // 头插
    HT[h] = s;
}
bool HashSearch(int key) {
    for (HNode *p = HT[Hash(key)]; p; p = p->next)
        if (p->key == key) return true;
    return false;
}

int HT2[M];                                  // 线性探测：-1空 -2已删
void LineInsert(int key) {
    int h = Hash(key);
    while (HT2[h] != -1 && HT2[h] != -2)     // 占用则探测下一格
        h = (h + 1) % M;
    HT2[h] = key;
}
bool LineSearch(int key) {

        h = (h + 1) % M;

void InsertSort(int a[], int n) {            // 稳定；基本有序时O(n)
    for (int i = 1; i < n; i++) {
        if (a[i] < a[i - 1]) {
            int t = a[i], j = i - 1;
            while (j >= 0 && a[j] > t) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = t;
        }
    }
}

void ShellSort(int a[], int n) {             // 不稳定；增量n/2递减到1
    for (int d = n / 2; d >= 1; d /= 2)
        for (int i = d; i < n; i++)
            if (a[i] < a[i - d]) {
                int t = a[i], j = i - d;
                while (j >= 0 && a[j] > t) {
                    a[j + d] = a[j];
                    j -= d;
                }
                a[j + d] = t;
            }
}

void BubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;
        for (int j = n - 1; j > i; j--)      // 从后往前，小元素上浮
            if (a[j - 1] > a[j]) {
                int t = a[j]; a[j] = a[j - 1]; a[j - 1] = t;
                flag = true;
            }
        if (!flag) return;                   // 一趟无交换→已有序
    }
}

算法思想：分治——Partition让枢轴归位（左≤它≤右），再递归两半。Partition是408考频最高的单函数（快排/第k小/划分题通用）。答题书写步骤：①取a[low]为枢轴暂存→②右找小填左、左找大填右→③相遇处归位枢轴→④递归左右。

int Partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] >= pivot) high--;   // 右端找小
        a[low] = a[high];
        while (low < high && a[low] <= pivot) low++;     // 左端找大
        a[high] = a[low];
    }
    a[low] = pivot;                          // 枢轴归位
    return low;
}

void QuickSort(int a[], int low, int high) {
    if (low < high) {
        int p = Partition(a, low, high);
        QuickSort(a, low, p - 1);
        QuickSort(a, p + 1, high);
    }
}

🎬 对应课程：L17 选择 + L18 堆排序 ｜ 考试规则见 L0/L26

算法思想：选择=每趟选最小放前面；堆排=建大根堆后反复"堆顶换末尾+下坠调整"。答题书写步骤（堆）：①从⌊n/2⌋起自底向上建堆O(n)→②n-1趟：堆顶换到i→③SiftDown(a,1,i-1)。

void SelectSort(int a[], int n) {            // 不稳定；比较恒为n(n-1)/2
    for (int i = 0; i < n - 1; i++) {
        int k = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] < a[k]) k = j;
        if (k != i) { int t = a[i]; a[i] = a[k]; a[k] = t; }
    }
}

void SiftDown(int a[], int k, int n) {       // 下标从1起：i孩子为2i,2i+1
    a[0] = a[k];                             // a[0]暂存
    for (int i = 2 * k; i <= n; i *= 2) {
        if (i < n && a[i] < a[i + 1]) i++;   // 取较大孩子
        if (a[0] >= a[i]) break;
        a[k] = a[i];                         // 大孩子上移
        k = i;
    }
    a[k] = a[0];
}
void HeapSort(int a[], int n) {              // a[1..n]，升序用大根堆
    for (int i = n / 2; i >= 1; i--)         // ①建堆 O(n)
        SiftDown(a, i, n);
    for (int i = n; i > 1; i--) {            // ②n-1趟
        int t = a[1]; a[1] = a[i]; a[i] = t; // 堆顶换到末尾
        SiftDown(a, 1, i - 1);               // O(logn)
    }
}

第6章 内部排序 · 6.5 归并排序必考模板考场禁用STL考频 ★★★

🎬 对应课程：L20 归并（相等先放左/逆序对） ｜ 考试规则见 L0/L26

算法思想：分治——递归拆半各自有序，再Merge两个有序段；任何输入恒定O(nlogn)且稳定。答题书写步骤：①mid拆半递归→②复制到辅助数组→③两段取小（取等号保稳定）→④接尾巴。

int b[MaxN];                                 // 辅助数组

void Merge(int a[], int low, int mid, int high) {
    for (int i = low; i <= high; i++) b[i] = a[i];
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {
        if (b[i] <= b[j]) a[k++] = b[i++];   // 取等号 → 稳定的关键
        else              a[k++] = b[j++];
    }
    while (i <= mid)  a[k++] = b[i++];
    while (j <= high) a[k++] = b[j++];
}
void MergeSort(int a[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(a, low, mid);
        MergeSort(a, mid + 1, high);
        Merge(a, low, mid, high);
    }
}
时间 恒定O(nlog₂n)空间 O(n)稳定 ✔趟数 ⌈log₂n⌉
STL替代标注：考排序必手写；机试 stable_sort 即归并。高频易错：①与快排对比：快排"先划分后递归"、归并"先递归后合并"；②k路归并趟数⌈log_k n⌉（外部排序考点）；③"n大且要求稳定"首选归并。
【例1·基础题】

8个元素2路归并共几趟？第1趟后形态？

查看解析

3趟（⌈log₂8⌉）。第1趟后4个长度2的有序段，第2趟2个长度4，第3趟完成。

第6章 内部排序 · 6.6 基数排序（附计数排序思想）考场禁用STL考频 ★★

🎬 对应课程：L21 分布排序（基数LSD逐位稳定） ｜ 考试规则见 L0/L26

算法思想：不基于比较——LSD最低位优先，d趟"分配（r个队列）+收集"；计数排序=按值域计数直接写回。二者均突破比较排序O(nlogn)下界。答题书写步骤：①按个位分配收集→②十位→…→d位；同位相同保持先来后到（队列FIFO→稳定）。

void CountSort(int a[], int n, int k) {      // 值域0..k，O(n+k)
    int cnt[MaxK] = {0};
    for (int i = 0; i < n; i++) cnt[a[i]]++;
    int idx = 0;
    for (int v = 0; v <= k; v++)
        while (cnt[v]-- > 0) a[idx++] = v;
}

// 基数排序（LSD）：d位十进制，r=10个基数队列
// for (int i = 1; i <= d; i++) {
//     ① 分配：digit = (a[j] / p) % r 入 queue[digit]，p = r^(i-1)
//     ② 收集：queue[0..r-1] 依次出队接回 a[]
// }
// 总复杂度 O(d(n+r))，空间O(r)，稳定
计数 O(n+k)/O(k) 稳定基数 O(d(n+r))/O(r) 稳定均不基于比较
STL替代标注：笔试手写流程。高频易错：①第i趟后"按后i位有序"；②适用：n大、位数d小（手机号/扑克牌）；③复杂度无log项——比较类下界对它无效。
【例1·基础题】

{209,386,7,48,123,76}按个位分配收集后的序列？

查看解析

个位：9,6,7,8,3,6 → 分配 3:{123} 6:{386,76} 7:{7} 8:{48} 9:{209} → 收集：123, 386, 76, 7, 48, 209。386在76前（FIFO保稳）。

下列排序中不基于比较的是？基于比较的排序时间下界是？

  • "第i趟后的序列"题型：插入/希尔看"前缀/分组有序"；冒泡/快排看"有元素归位"；堆排看"堆顶交换+调整"；归并看"成段有序"。
