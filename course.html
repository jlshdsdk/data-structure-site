第1章 · 绪论：数据结构概述（对应PPT：Lecture 1，66页）

这一章回答一个问题：什么是数据结构？答案就三个词——逻辑结构、存储结构、操作。

L1 · 数据结构概述：逻辑结构 · 存储结构 · 操作408高频考点

本节导入：今天我们来讲这门课的第一个概念性问题——到底什么是"数据结构"？Wirth 有一句名言（PAGE 4、13）：算法 + 数据结构 = 程序。编程语言和框架是"招式"，数据结构与算法是"内功"——一个招式能发挥多大威力，取决于出招人的内功（PAGE 25）。这句话就是这门课存在的意义。

一、数据的三层结构（PAGE 42-44）

  • 数据：计算机程序处理的对象统称。简单的如整数、实数、字符串；复杂的如图像、音频、程序本身。
  • 数据元素（也叫数据成分、结点、顶点）：数据由多个数据元素组成。
  • 数据项（也叫域、字段）：数据元素由描述其属性的多个数据项组成。

课堂例（PAGE 44）：个人图书表格——整张表是数据，表中的一行是数据元素，表中的一列属性是数据项。这个三层关系是所有后续讨论的颗粒度基础。

二、逻辑结构：元素之间是什么关系（PAGE 45-52）

用结点表示数据元素、箭头表示前驱/后继关系，逻辑结构分四类（PAGE 47）：

逻辑结构关系特征（PPT原文口径）典型例子
线性结构（线性表）有且仅有一个始结点和一个终结点；始结点只有后继、终结点只有前驱；每个内结点有且仅有一个前驱和一个后继a→b→c→d→e（PAGE 48）
层次结构（树）根没有前驱；除根外每个结点有且仅有一个前驱，但可以有多个后继k1 为根的 9 结点树（PAGE 50）
网状结构（图）每个结点可以有任意多个前驱和后继N={A,B,C,D,E}（PAGE 51）
集合每个结点都没有前驱和后继（除同属一个集合外无任何关系）N={A,B,C,D,E}（PAGE 52）

三、存储结构：关系怎么存进计算机（PAGE 53-62）

设计存储结构要回答两个问题：①数据元素怎么存；②逻辑关系怎么存。四种基本方式（PAGE 53）：

存储结构做法优点缺点
顺序存储元素连续存放，逻辑相邻=物理相邻基于下标的检索效率高 O(1)插入删除要整体搬移 O(n)（元素大时更惨）
链接存储元素任意存放，用指针表达前驱后继插入删除只改指针 O(1)按关键字/下标检索低效 O(n)
散列存储散列函数 h(K)=K 映射到存储地址理想情况 O(1) 定位冲突：K1≠K2 但 h(K1)=h(K2)（PAGE 56-57，第八章细讲）
索引存储建索引表存指针，指向实际元素对索引的检索快（数据在外存、索引在内存时优势巨大）额外空间（PAGE 58-60）

四种存储结构可以灵活组合使用；应根据问题特点选择（PAGE 62）。

怎么衡量一个算法好不好？这一章给出一把尺子：时间复杂度与空间复杂度，以及大O记号。期末和408都年年在这里出选择题。

L2 · 算法概述：复杂度分析与大O记号408高频考点

本节导入：上一节我们知道了"组织数据"，这一节解决"怎么衡量算法好坏"。为什么不直接掐表测运行时间？因为实际运行时间依赖机器、语言和实现细节（C 快于 Java/Python，printf/scanf 快于 cout/cin）——所以我们需要一个与机器无关、与语言无关的度量标准（PAGE 14-15）。

一、算法与它的五个特性（PAGE 7-9）

算法：解决问题所采用的方法或步骤——由有限条指令构成、规定解决特定问题的一系列操作。五个特性（PAGE 8）：

  1. 有限性：有限步后必须终止；
  2. 确定性：每条指令含义明确无二义；
  3. 输入：0个或多个；
  4. 输出：1个或多个；
  5. 可行性：每个操作都可用基本运算有限次完成。

算法 vs 程序（PAGE 9）：程序是算法的语言实现；程序可以不满足有限性——比如 while(1){} 和操作系统。这是判断题爱考的区分点。

评价准则（PAGE 10-16）：正确性、时间复杂性、空间复杂性、可读性、健壮性（鲁棒性：能应对各种极端输入）。

二、基本运算与三种时间复杂性（PAGE 27-39）

基本运算（关键运算）：算法中起主要作用、费时最多的操作——排序数"比较"、插入删除数"移动"、矩阵数"乘加"。时间复杂性 = 基本运算次数，是问题规模 n 的函数（PAGE 15、27）。

同一算法不同输入次数可能不同（PAGE 30），于是有三种口径（PAGE 31）：设输入 I 的概率 P(I)、基本运算次数 T(I)：

  • 平均 E(n) = Σ P(I)·T(I)；最好 = min T(I)；最坏 = max T(I)。

课堂主例：Find 算法（PAGE 30-39）——数组 R[1..n] 中找 K，基本运算是"比较"：K=R[1] 最好 1 次；K=R[n] 或不在表中，最坏 n 次；平均：设 K 在表中的概率为 q，则 K=R[i] 的概率为 q/n，"不在表中"概率 1−q（比较 n 次！不是 0 次），得 E(n) = q(n+1)/2 + (1−q)n；已知 K 在表中（q=1）时 E(n)=(n+1)/2——这正是408顺序查找 ASL 的经典结论。

三、大O / Ω / Θ（PAGE 46-55）

精确表达式没必要，我们只关心变化趋势（PAGE 46-47）：T(n)=n²+100n+log₁₀n+1000，n 大时第一项说了算，取 g(n)=n²。

记号定义（存在什么常数、什么不等式）含义
T(n)=O(g(n))∃正常数C和n₀，∀n≥n₀：T(n) ≤ C·g(n)上界：增长至多和 g(n) 一样快
T(n)=Ω(g(n))∃正常数C和n₀：T(n) ≥ C·g(n)下界
T(n)=Θ(g(n))∃C₁、C₂：C₁g(n) ≤ T(n) ≤ C₂g(n)同阶（上下界同时给出）

验证例（PAGE 51）：T(n)=3n−2，取 C=3、n₀=1，3n−2≤3n，故 O(n)；T(n)=(n+1)²≤4n²（n≥1），故 O(n²)。

📌【PPT课堂重点】必背两组表
① 量级全序（PAGE 58）：O(1) < O(loglogn) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2ⁿ)
② 大O四条化简性质（PAGE 63-66）：常系数可忽略 O(df(n))=O(f(n))；低次项可忽略 O(nᵃ+nᵇ)=O(nᵃ)（a>b>0）；对数底可忽略 O(logₐn)=O(logn)；对数常数次幂可忽略 log(nᶜ)=O(logn)。多项式看最高次项。
③ 级数（PAGE 68-69）：Σk = n(n+1)/2 = O(n²)；Σk² = O(n³)；一般 Σk^d = O(n^{d+1})；调和级数 1+1/2+…+1/n ≈ ln n = O(logn)——后面分析"内层依赖外层"的循环全靠它。

五、均摊时间复杂度（PAGE 89-97）课件拓展·408不考

一、单链表与哨位结点（PAGE 5-17）

结点结构：struct Node{ int data; Node* next; };。头指针 head 指向表头，尾指针 tail 指向表尾（PAGE 5）。

📌【PPT课堂重点】哨位（哨兵）结点（PAGE 6-7）
在表前端增加一个不算表中实际结点的特殊表头结点，作用是简化边界条件的处理（对表头的插入删除不再需要特判）。表长 = 非哨位结点个数；只有哨位则为空表。讨论"第k个结点"均指第 k 个实际结点。
⚠️ 术语对齐：408/严蔚敏教材把哨兵叫"头结点"、第一个数据结点叫"首元结点"；本课件"头结点"指第一个数据结点。跨教材复习务必对齐！

四个基本操作（函数签名与核心语句）：

Node* Find(Node* head, int k) {          // 返回第k个结点地址，k<0返回NULL
    Node* p = head;                      // 从哨位出发走k步
    for (int i = 0; i < k && p != NULL; i++) p = p->next;
    return p;                            // p==NULL说明链表长度不足k
}
Node* Search(Node* head, int item) {     // 按值查找：从第1个实际结点开始！
    for (Node* p = head->next; p != NULL; p = p->next)
        if (p->data == item) return p;
    return NULL;
}
void Delete(Node* head, int k) {         // 删除第k个结点
    if (k < 1) return;                   // 不能删哨位
    Node* p = Find(head, k - 1);         // 先找前驱
    if (p == NULL || p->next == NULL) return;
    Node* q = p->next;
    p->next = q->next;                   // 跨过q
    delete q;                            // ADL记号：AVAIL<-q（归还可利用空间表）
}
void Insert(Node* head, int k, int item) {   // 在第k个结点后插入
    Node* p = Find(head, k);
    Node* s = new Node; s->data = item;
    s->next = p->next;                   // ①先接后继（顺序不能反！）
    p->next = s;                         // ②再改前驱
}
📌【PPT课堂重点】结论（PAGE 13、16）
链表中插入/删除一个结点，只需改变一个或两个相关结点的指针，不对其它结点产生影响——这就是"插删 O(1)"的来源。插入两句 s->next=p->next; p->next=s; 的顺序不能颠倒，反了会丢失后继。

四、静态链表与侵入式链表（PAGE 38-49）

静态链表（PAGE 39-41）：没有指针类型的语言里，用数组下标模拟指针：int data[12]; int next[12];，next 值 −1 表示表尾（NULL）。静态双向循环链表（PAGE 43-45）核心思想——"盒子不动，指针动"：盒子在数组中的位置永远不变（可 O(1) 定位任意盒子），移动只改 prev/next 两个数组：

// 删除盒子x：
next[prev[x]] = next[x];  prev[next[x]] = prev[x];
// x插到y右边：
prev[next[y]] = x;  next[x] = next[y];  prev[x] = y;  next[y] = x;
// x插到y左边：
next[prev[y]] = x;  prev[x] = prev[y];  next[x] = y;  prev[y] = x;
// 指令 L X Y = 删X + 插到Y左边；R X Y = 删X + 插到Y右边

int kthToLast(ListNode* head, int k) {
    ListNode *slow = head, *fast = head;
    for (int i = 1; fast != NULL && i < k; i++) fast = fast->next;  // fast到第k个
    if (fast == NULL) return 0;              // 长度不足k
    while (fast->next != NULL) { slow = slow->next; fast = fast->next; }
    return slow->val;
}
ListNode* detectCycleEntrance(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (fast == slow) {                   // 相遇后：一头回起点
            ListNode *p1 = head, *p2 = fast;
            while (p1 != p2) { p1 = p1->next; p2 = p2->next; }
            return p1;                        // 同速再相遇=环入口
        }
    }
    return NULL;
}

③ 总数（PAGE 93-98）：n 个元素的栈混洗 ⟺ n 对括号匹配，总数 = C(2n,n) − C(2n,n−1) = Catalan(n) = C(2n,n)/(n+1)；Catalan(6)=132。 
bool check(int a[], int b[], int n) {   // a入栈序列 b待验出栈序列
    stack s;  int k = 0;                 // k扫描入栈序列
    for (int i = 0; i < n; i++) {        // i扫描出栈序列
        while (s.empty() || s.peek() != b[i])
            if (k < n) s.push(a[k++]);   // 压到栈顶等于目标为止
            else return false;           // 入栈耗尽仍不匹配→非法
        s.pop();                         // 栈顶出栈
    }
    return true;
}

一、朴素（BF）模式匹配（PAGE 6-30）

第 i 趟看 P 是否出现在 S 的第 i 个位置。失配三动作（PAGE 19）：P 右移1位、i 回退到 i−j+1、j 回退到 0；匹配成功（j==m）返回 i−m。关键运算是字符比较，最坏 O(n·m)（PAGE 20）。

平均情况（PAGE 21-29，东京大学考研题）：设字符集 k 种、单次匹配概率 1/k，每趟期望比较 T_i=(1−(1/k)^m)/(1−1/k)≤2，故平均 T≤2n——字符集越大，单次比对成功率越低、越接近线性（结论记牢，证明了解）。

二、KMP：利用"经验"与"教训"（PAGE 31-71）

朴素匹配的浪费在哪？三个优化途径（PAGE 38）：P 能否多移几位？i 可否不回退？j 可否不退到0？答案是：利用模式串自身的重复性。

📌【PPT课堂重点】next 函数（失败函数/前缀函数，PAGE 44-46）——本讲核心
在 p_j 失配（s_i≠p_j，且已匹配 s_{i−j}…s_{i−1}=p_0…p_{j−1}）：在 p_0…p_{j−1} 中找最长相等前后缀，设长度 k，则下次匹配 s_i 直接与 p_k 比较——i 不动，j 回退到 k（即模式串右移 j−k 位）。
next(j) = −1（j=0）；max{k | p_0…p_{k−1} = p_{j−k}…p_{j−1}，0<k<j}；0（不存在）
① 必须取"最长"（取短了会漏掉成功匹配，PAGE 40-41 反例专门强调）；② next 只与 P 有关、与 S 无关，可预处理；③ next 与教材失败函数的换算：f(j) = next(j+1) − 1（PAGE 84，应对不同教材口径）。 
int KMP(char *S, char *P, int n, int m) {
    int next[maxm], i = 0, j = 0;
    buildNext(P, next, m);
    while (j < m && i < n) {
        if (j == -1 || S[i] == P[j]) { i++; j++; }   // j==-1：p0失配，整体右移1位
        else j = next[j];                             // 失配：j回退，i不动
    }
    return (j == m) ? i - m : -1;
}
void buildNext(char *P, int next[], int m) {          // 递推：已知next(j)=k
    int k = next[0] = -1;
    for (int j = 0; j < m - 1; j++) {
        while (k >= 0 && P[k] != P[j]) k = next[k];   // 链式回退找次长相等前后缀
        next[j + 1] = ++k;                            // P[k]==P[j]则next(j+1)=k+1
    }
}
📌【PPT课堂重点】复杂度（PAGE 70-71）
buildNext：++k 至多 m 次、k=next[k] 次数不超过 k 的增加次数 → 字符比较 ≤2m，O(m)；KMP 匹配：i 只增不减、j 增减相抵 → 比较 ≤2n，O(n)。KMP 总时间 O(n+m)。字符集越小（P_r=1/k 越大），KMP 相对朴素的优势越大（PAGE 83）。

三、KMP 的拓展与改进（PAGE 72-98）

  • 统计出现次数与所有位置（PAGE 72，吉大20级上机）：匹配成功时 cnt++、输出 i−m，然后 j=next[j]（"假装"失配） 继续找下一处——buildNext 要多算一位到 next[m]。
  • 隐藏应用（PAGE 73-75）：最长相等前后缀=next[n]、第二长=next[next[n]]、最长重复前缀=max next[i]；最长回文前缀用 p#p⁻¹ 拼接 + KMP；最短补成回文（LC214）。课件拓展·408不考

  • KMP 改进 next2/nextval（PAGE 85-97）：原始 next 的不足——在 p_j 失配说明 s_i≠p_j，若 p_k=p_j，则下次 s_i≠p_k 必然失败（"只用经验没用教训"）。改进：确定下一位置时额外保证 p_k≠p_j。buildNext2 核心：next2[j+1] = (P[j+1]!=P[++k]) ? k : next2[k];课件拓展·408不考

Tutorial 1 · 字符串的模糊匹配：编辑距离与 LCS课件拓展·408不考

本节导入：精确匹配要求一字不差，但现实中基因序列比对（黑猩猩与人 DNA 相似度 86–89%）、论文查重需要"差不多就算匹配"——模糊匹配（PAGE 2）：只要有一定程度的相似就认为匹配成功。怎么量化"相似"？两个工具：编辑距离和 LCS。

一、编辑距离（PAGE 5-15）

定义：一个串变另一个串所需最少编辑操作次数（增加/删除/替换各算一次）。递推（PAGE 11-12）：

情形递推式
S_i = P_jDist(i,j) = Dist(i−1, j−1)
S_i ≠ P_jDist(i,j) = min{ Dist(i−1,j−1)【替换】, Dist(i,j−1)【插入P_j】, Dist(i−1,j)【删S_i】 } + 1

边界：D[i][0]=i、D[0][j]=j（变成空串要删 i/j 次——不是0！）。复杂度 O(nm)。

【PPT原题·PAGE 6、13】FOOD→MONEY

求编辑距离；并填表 S="BCD"、P="ABC" 求 D[3][3]。

查看解析

FOOD→MONEY：4 次（F→M、O→N、插入E、D→Y）。BCD vs ABC 填表逐格：D[1][1]=1、D[1][2]=1(B=B取左上)、D[1][3]=2；D[2][1]=2、D[2][2]=2、D[2][3]=1(C=C)；D[3][1]=3、D[3][2]=3、D[3][3]=2（B→A、D→C 两次替换）。

二、最长公共子序列 LCS（PAGE 16-23）

子序列：按原相对次序取若干字符（不要求连续——与子串的区别）。递推：

情形递推式
S_i = P_jLCS(i,j) = LCS(i−1,j−1) + 1
S_i ≠ P_jLCS(i,j) = max{ LCS(i−1,j), LCS(i,j−1) }（不含左上项，与编辑距离对照记）

边界 LCS[i][0]=LCS[0][j]=0。复杂度 O(nm)。三个变形结论（PAGE 24-26）：①最少删成相等 = (n−k)+(m−k)（k为LCS长）；②S 的最长回文子序列 = LCS(S, S⁻¹)；③最少删成回文 = n − 最长回文子序列长。

L7 · 树和二叉树的定义与性质408高频考点

本节导入：从这一讲起我们进入课程的重头戏——树。为什么要学树？家谱、组织机构、文件系统、软件模块划分（PAGE 4-12），凡是"一对多"的层次关系都用树。今天先把定义和五条性质打牢——期末考研年年在这里出计算题。

一、树的定义与术语（PAGE 13-22）

树（PAGE 13）：有限结点集合 T：空则为空树；非空则 ①有根 root(T)；②其余结点分成 m(m≥0) 个不相交的集合 T1..Tm，且均为树（根的子树）。子树次序被指明为有序树（PAGE 15）。

  • 度：结点的子结点数；树的度 = max。度为0是叶结点，度>0是分支结点（PAGE 17）。
  • 层数（深度）：根层数为0（本课件约定！），其余=父+1；树高/树深=最大层数；结点高度=以它为根的子树高度（PAGE 19-20）。
  • 路径：vi+1 是 vi 子结点的序列；路径长度=边数；根到某结点的路径长度恰为该结点层数（PAGE 21）。祖先/子孙（PAGE 22）。

二、二叉树：定义与五条性质（PAGE 24-33）

二叉树（PAGE 24）：空集，或一个根 + 两棵不相交的左、右子树。特征（PAGE 25）：每结点最多2孩子；子树有左右之分，单孩子也须指明左右（五种形态）。

📌【PPT课堂重点】五条引理（PAGE 28-33，全部给过证明）
  1. 第 i 层至多 2^i 个结点（i≥0）——归纳法。
  2. 高度 k 的二叉树至少 k+1 个结点（单支链）。
  3. 高度 k 的二叉树至多 2^{k+1}−1 个结点（各层求和）。
  4. n0 = n2 + 1（任意二叉树！）：n=n0+n1+n2；边数下往上数 e=n−1、上往下数 e=2n2+n1，联立即得。
  5. （为完全二叉树铺垫的编号/高度引理见下。）

三、满二叉树与完全二叉树（PAGE 34-48）

  • 满二叉树（PAGE 34-36）：高度 k 且有 2^{k+1}−1 个结点。特点：叶都在最后一层；非叶都有两孩子；叶数=非叶数+1。k 个叶结点的满二叉树共 2k−1 个结点。
  • 完全二叉树（PAGE 37-40）：按层次顺序编号恰好对应同高满二叉树的前 n 个结点。特点：只有最下两层度可小于2；最下层结点靠左；叶只在最后两层；仅编号最大的非叶结点可无右孩子。
📌【PPT课堂重点】完全二叉树编号与高度（PAGE 42-46，顺序存储的地基）
n 结点按层次从1编号：①i≠1 时父=⌊i/2⌋；②2i≤n 时左孩子=2i；③2i+1≤n 时右孩子=2i+1。
推论（PAGE 44）：非叶结点 ⌊n/2⌋ 个、叶结点 ⌈n/2⌉ 个。
高度（PAGE 46）：h = ⌊log₂n⌋（由 2^k ≤ n < 2^{k+1}）。
高度 k 的完全二叉树最少 2^k 个结点（高 k−1 的满二叉树 +1，PAGE 41）。

本节导入：性质有了，今天解决"怎么存、怎么遍历"。遍历是二叉树一切操作的总纲——找父、计数、求高、复制、建树，全是遍历的实例化。

一、三种存储结构（PAGE 4-14）

  • 二叉链表（PAGE 11-13）：struct TreeNode{int data; TreeNode *left,*right;};——ADL 记法 Left(t)/Data(t)/Right(t)。
  • 三叉链表（PAGE 14）：再加 Parent 域。

二、递归遍历与分治（PAGE 16-29）

先根（根左右）/中根（左根右）/后根（左右根），所得序列称先/中/后根序列。时间 O(n)、空间 O(h)（递归栈）。遍历即分治：大问题拆成"访问根/遍历左/遍历右"三个不重叠子问题；自顶向下递归=分治，自底向上递推+查表=动态规划（PAGE 22）。

三、非递归遍历（PAGE 31-53）必考模板

📌【PPT课堂重点】非递归先根/中根 + 进出栈对应（PAGE 32-44）
先根：沿左分支边访问边压栈；弹栈后转右子树。中根：沿左分支压栈不访问；弹栈访问后转右。两者代码只差 visit 的位置。
关键结论（PAGE 44、87）：先根遍历的进栈序列 = 中根遍历的进栈序列；出栈序列亦然——先根算法"进栈顺序=访问顺序"，中根算法"出栈顺序=访问顺序"。这是二叉树计数化为栈混洗的桥梁！
后根（PAGE 46-52）：弹栈 p 前须先访问 p 的右子树。版本1：取栈顶不弹 + pre 记录上一个刚访问的结点，p 无右子树或 right==pre 时才弹出访问；版本2：栈存二元组(结点,标号)，i=1/2/3 分别表示准备遍历左/右/访问自身，结点可多次进出栈。 
void InOrder2(TreeNode *t) {
    vector<TreeNode*> stk;                   // 手动栈
    TreeNode *p = t;
    while (p || !stk.empty()) {
        if (p) { stk.push_back(p); p = p->left; }   // 沿左链入栈（不访问）
        else {
            p = stk.back(); stk.pop_back();
            visit(p);                       // 弹栈访问
            p = p->right;                   // 转右子树
        }
    }
}

六、二叉树的重建与计数（PAGE 80-100）

📌【PPT课堂重点】重建唯一性结论（PAGE 80-97）
先根+中根可唯一重建（先根定根、中根分左右）；后根+中根亦可；先根+后根不能（无法区分独子左右，反例先根AB/后根BA）；层次+中根可以；中根序列 + 任意一种其他序列都可唯一确定二叉树（清华考研、吉大期末考过中根+层次）。

二叉树计数（PAGE 86-88）：n 结点按先根编号 1..n，中根序列个数 = 树的形态数；由"进栈=先根、出栈=中根"化为栈混洗计数 = Catalan(n)。

先+后求结构数（PAGE 98-100，洛谷P1229）课件拓展·408不考：先根 X 紧跟 Y、后根 Y 紧邻 X 前（preorder[i]==postorder[j] 且 preorder[i+1]==postorder[j−1]）说明该结点单孩子——每多一个度为1的结点，结构数×2。先根ABC+后根CBA → 4 种。

TreeNode* buildTree(char *preorder, char *inorder, int n) {
    if (n <= 0) return NULL;
    TreeNode *root = new TreeNode(preorder[0]);      // 先根首=根
    int k = find(inorder, n, root->data);            // 在中根中定位根
    root->left  = buildTree(&preorder[1], &inorder[0], k);          // 左子树k个
    root->right = buildTree(&preorder[k+1], &inorder[k+1], n-k-1); // 右子树n-k-1个
    return root;
}   // 最好/平均O(nlogn)，最坏O(n²)（退化时find线性扫描）

L9 · 线索二叉树408高频考点

本节导入：腾讯面试题引入（PAGE 7）：没有父指针，怎么快速找中根后继？——只能遍历 O(n)。而 n 个结点的二叉树 2n 个指针域只有 n−1 个被使用（每条边占一个），剩下 n+1 个空指针闲着——让它们存前驱后继，这就是线索二叉树（PAGE 9-11）。

一、结构与两个天然性质（PAGE 12-17）

结点加两个标志位：LThread/RThread=0 指孩子（真指针），=1 是线索；Left 无左孩子时指中根前驱、Right 无右孩子时指中根后继。按中根/先根/后根线索化分别得中序/先序/后序线索二叉树。

📌【PPT课堂重点】（PAGE 14、17）
性质1：中根序列第一个结点一定无左孩子、最后一个一定无右孩子。
性质2：结点是叶 ⟺ LThread=RThread=1。
目的：在中序线索二叉树中方便地找中序前驱/后继，且不需太多额外空间。

二、四个基本操作（PAGE 19-28）必考模板

TreeNode* FirstInOrder(TreeNode* t) {      // 中根第一：沿左链到底
    TreeNode *p = t;
    while (p->LThread == 0) p = p->left;
    return p;                              // O(h)
}
TreeNode* LastInOrder(TreeNode* t) {       // 中根最后：沿右链到底
    TreeNode *p = t;
    while (p->RThread == 0) p = p->right;
    return p;
}
TreeNode* NextInOrder(TreeNode* p) {       // 后继
    if (p->RThread == 1) return p->right;            // 有线索直接走
    return FirstInOrder(p->right);                   // 否则=右子树中根首结点
}
TreeNode* PreInOrder(TreeNode* p) {        // 前驱
    if (p->LThread == 1) return p->left;
    return LastInOrder(p->left);                     // =左子树中根末结点
}
// 线索遍历：不用递归不用栈，空间O(1)
for (TreeNode *p = FirstInOrder(t); p != NULL; p = NextInOrder(p)) visit(p);

三、中序线索化与实现方案（PAGE 29-34）

线索化：使二叉树变为线索二叉树的过程——把中根遍历的"访问结点"具体化为"建立当前结点与前驱的线索关系"：指针 p 指当前访问结点，全局 pre 始终指向 p 的中根前驱（初值 NULL）。成对判断：p 无左孩子→p 的左指针对 pre 建线索；pre 存在且无右孩子→pre 的右指针对 p 建线索；然后 pre=p。算法结束后单独补最后结点：pre->RThread=1（其 right 此时仍为 NULL）。

实现方案（PAGE 32-34）：①Tag 字节压缩——C/C++ 没有 1bit 变量，用 1 字节 4 种状态编码两标志组合；②扩展二叉树——把 LThread/RThread 换成实打实的 Pred/Succ 指针域，空间换时间，找前驱后继从 O(h) 降到 O(1)。课件拓展·408不考

本节导入：一般树孩子数不定，怎么存？核心思路：树 ↔ 二叉树互相转换，然后复用二叉树的一切算法。

一、树/森林 ↔ 二叉树转换（PAGE 3-10）

📌【PPT课堂重点】转换规则与"自然对应"（PAGE 4-10）
树→二叉树：①兄弟结点间加连线 ②保留与左孩子的连线、去掉与其他孩子的连线 ③整形。规律：左孩子仍是左孩子，右兄弟变成右孩子，转换后二叉树的根无右孩子。
森林→二叉树：每棵树先转换，以第一棵的根为总根，其余树的根依次作前一棵根的右孩子（或引入虚拟根法）。
二叉树→树：当且仅当右子树为空；→森林：右子树非空。
自然对应：任一森林对应唯一一棵二叉树，反之亦然。

二、树的存储结构（PAGE 12-28）

存储做法优缺点（PPT口径）
双亲表示法（顺序）层次顺序编号 + Father[] 存父下标找父方便；求子结点要遍历整棵树
孩子表示法（顺序）固定个数孩子域便于孩子操作；求父不便、空间浪费
孩子链表每结点挂孩子链表，头指针入数组便于子不便于父；加父域=父亲孩子链表
左孩子-右兄弟（链接）Data + FirstChild + NextBrother与二叉链表完全一样，直接复用二叉树算法（使用最广）

"序列+度"表示（PAGE 14-19）课件拓展·408不考：三条定理——先根序列+各结点度、后根序列+度、层次序列+度均可唯一确定树。重建方向：先根+度从右往左归并（结点度 k 取最近的 k 个子树）；后根+度从左往右。优点不存指针省空间，适合输入输出与建树。

三、树与森林的遍历（PAGE 30-42）

📌【PPT课堂重点】两条对应关系（PAGE 32、34，选择题核心）
森林的先根序列 = 其对应二叉树的先根序列；森林的后根序列 = 其对应二叉树的中根序列。
树的先根：访问根→从左到右先根遍历诸子树；树的后根：先遍历诸子树→访问根。树没有中根遍历（子树数不定，"根在中间"无统一定义——PAGE 17 提问）。 
struct TreeNode { int data; TreeNode *FirstChild, *NextBrother; };

void PreOrder(TreeNode* t) {                      // 树的先根遍历
    visit(t->data);
    for (TreeNode *p = t->FirstChild; p != NULL; p = p->NextBrother)
        PreOrder(p);
}
TreeNode* FindFather(TreeNode* t, TreeNode* p) {  // 找父：扫孩子链
    if (!t || !p || p == t) return NULL;
    for (TreeNode *chd = t->FirstChild; chd != NULL; chd = chd->NextBrother) {
        if (chd == p) return t;                   // t是父
        TreeNode *r = FindFather(chd, p);         // 进子树找
        if (r) return r;
    }
    return NULL;
}
void Del(TreeNode* p) {                           // 释放子树：沿孩子链先记next再删
    for (TreeNode *c = p->FirstChild; c != NULL; ) {
        TreeNode *next = c->NextBrother;          // 先记兄弟再Del，防断链
        Del(c);
        c = next;
    }
    delete p;
}

// p 是长子则 fa->FirstChild = p->NextBrother；
// 否则找左兄弟 pre，pre->NextBrother = p->NextBrother；最后 Del(p)

森林层次遍历（PAGE 42）：先把每棵树的根沿 NextBrother 链入队；出队访问 p，再把 p 的孩子沿 FirstChild→NextBrother 链依次入队。

三、并查集（PAGE 80-107）【A级；2022年起408入纲】

定义（PAGE 84-85）：维护一组不相交集合，支持三操作：MAKE_SET(x) 建新集合（x 为代表元）、UNION(x,y) 合并、FIND(x) 返回 x 所在集合代表元。树表示（PAGE 86-89）：树↔集合、结点↔元素、根↔代表元；只需向上访问——Father[] 数组（根为0），UNION 即让一根的父指另一根。

📌【PPT课堂重点】两个优化与复杂度结论【A级】
① 路径压缩（PAGE 94-95）：FIND 找到根后把路径上所有结点的父亲改为根（两趟写法：Father[x]=FIND(Father[x]) 写在 return 前）。
② 按秩合并（PAGE 96-98）：秩=子树高度上界（路径压缩不改变秩）；秩大者作父，相等时新根秩+1。实现技巧：根的 Father 域空闲——Father[x]≤0 表示 x 是根，存秩的相反数。
③ 复杂度定理（PAGE 101）：m 次操作（Make_Set 共 n 次）同时用两优化，最坏 O(m·α(n))——α 是反阿克曼函数，每个操作均摊接近 O(1)。
④ 应用范式：等价性问题（等价类↔集合：初始逐个 Make_Set、输入等价对就 Union、查询比 Find）——省份数量（华为字节等面试题）：统计 Father[i]≤0 的根个数。 
int Father[N];                       // Father[x]<=0：x是根，值为秩的相反数
void MS(int x) { Father[x] = 0; }    // 或 -1 视口径；代表元即自身
int FIND(int x) {                    // 路径压缩：两趟
    if (Father[x] <= 0) return x;
    Father[x] = FIND(Father[x]);     // 上行找根，返回时顺带压缩
    return Father[x];
}
void UN(int x, int y) {              // 按秩合并
    int fx = FIND(x), fy = FIND(y);
    if (fx == fy) return;            // 同集合：跳过（防自环）
    if (Father[fx] < Father[fy])     // 负得更多=秩更大者作父
        Father[fy] = fx;
    else {
        if (Father[fx] == Father[fy]) Father[fy]--;   // 秩相等则新根秩+1
        Father[fx] = fy;
    }
}

L13 · 图的遍历及应用：DFS 与 BFS408高频考点必考模板

本节导入：图遍历=从某顶点出发访问所有顶点且每点恰一次——必须配 visited[]（初值0，访问置1）防重复（PAGE 4）。两条路线：DFS 一条道走到黑；BFS 层层推进。

一、DFS（PAGE 5-33）

一、拓扑排序（PAGE 3-22）

AOV网（PAGE 6）：顶点表示活动、有向边表示先后关系——AOV网不能有环（DAG）。拓扑排序三步（PAGE 8）：①选入度0的顶点输出 ②删除它及其引出的所有边 ③重复至全部输出；排不完⟺有环⟺任务不可行。序列未必唯一。

bool TopoOrder(Vertex Head[], int n) {     // O(n+e)
    int InDegree[N] = {0}, stack[N], top = -1;
    getInDegree(Head, n, InDegree);        // ①求入度 O(n+e)
    for (int i = 1; i <= n; i++)           // ②入度0者进栈
        if (InDegree[i] == 0) stack[++top] = i;
    int cnt = 0;
    while (top >= 0) {
        int j = stack[top--];              // ③弹栈输出
        printf("%d ", j); cnt++;
        for (Edge *p = Head[j].adjacent; p; p = p->link)
            if (--InDegree[p->VerAdj] == 0)   // ④删边：入度减到0入栈
                stack[++top] = p->VerAdj;
    }
    return cnt >= n;                       // 输出不全→有环
}

二、Dijkstra（PAGE 20-66）

思想（PAGE 41-42）：顶点分 S（已确定）与 V−S，按与源点最短距离递增的顺序逐个把顶点加入 S。三步：①从 V−S 选 dist 最小的 v 入 S（此时 Dv 即最终最短距离）②用 v 松弛邻居：Dv+w(v,w)<Dw 则更新 ③重复。

const int INF = 0X3f3f3f3f;
void Dijkstra(Vertex *Head, int n, int u, int dist[], int pre[]) {
    int S[N] = {0};
    for (int i = 1; i <= n; i++) { dist[i] = INF; pre[i] = -1; }
    dist[u] = 0;
    for (int t = 1; t <= n; t++) {
        int v = findMin(S, dist, n);       // V-S中dist最小者，O(n)
        if (v == -1) break;
        S[v] = 1;                           // 入S：贪心确认，不可反悔
        for (Edge *p = Head[v].adjacent; p; p = p->link)
            if (S[p->VerAdj] == 0 && dist[v] + p->cost < dist[p->VerAdj]) {
                dist[p->VerAdj] = dist[v] + p->cost;   // 松弛
                pre[p->VerAdj] = v;
            }
    }
}   // 邻接表O(n²+e)；邻接矩阵O(n²)（课下思考PAGE 46）

正确性原理（PAGE 56）："任意最短路的前缀也是最短路"（反证易明）；pre 数组可同时存源点到所有点的最短路。不适用负权（PAGE 59）：负权会让"已入 S 的最小 Dv"失效；负权用 Bellman-Ford O(ne)（OSPF 用 Dijkstra、RIP/BGP 用距离向量——PAGE 60）。堆优化可到 O(nlogn+e)（详见 L18 优先队列）。

L16 · 最小支撑树及图应用408高频考点必考模板

本节导入：n 个地点修最便宜的连通网——最小支撑树（MST）。两大算法 Prim 和 Kruskal，背后是同一条定理。

一、MST 与最小跨边定理（PAGE 4-10）

支撑树：n 顶点 + n−1 条边的连通子图（无环）；MST=边权总和最小的支撑树。跨集合边：端点分属 S 与 V−S 的边。最小跨边定理（PAGE 7-10）："权值最小的跨集合边一定在某棵 MST 里"——反证：MST 不含它，则 u,v 路径上必有另一条跨边(s,t)，换之权和更小，矛盾。这是两个算法的共同依据。

二、Prim（PAGE 12-42）

三步（PAGE 21）：①任选起点 u，S={u} ②取最小跨集合边(u,v)加入 MST，v 入 S ③重复至 S=V。实现靠两个数组：Lowcost[v]=v 到 S 的最小跨边权值、pre[v]=该边在 S 中的端点；每选一个 v 入 S 就用它更新邻居（PAGE 22-26）。O(n²)，FindMin 返回 −1 判不连通（此时返回含起点的连通分量的 MST）。

📌【PPT课堂重点】Dijkstra vs Prim 一行之差（PAGE 32-33，"仔细体会两段代码的细微不同"）
选点后更新邻居的条件：
Dijkstra：dist[v] + G[v][w] < dist[w]（累加路径长）
Prim：G[v][w] < Lowcost[w]（单边直比）——两算法最易混的地方！

三、Kruskal（PAGE 44-53）

三步（PAGE 45）：①T 含 n 顶点 0 边（n 个分量）②选权最小边：若加入不产生环（两端点在不同分量）则加入，分量数减一 ③重复至一个分量。实现：边按权排序 + 并查集判环（Find(u)≠Find(v) 才加入并 Union），存图用边集数组 struct Edge{int head,tail,weight;}。复杂度 O(e·loge)（排序主导）。正确性：当前最小边必是其一侧分量的最小跨边（PAGE 52）。

📌【PPT课堂重点】对比结论（PAGE 53，2023清华考研判断题原型）
Prim O(n²) 适合稠密图；Kruskal O(eloge) 适合稀疏图；两者均为贪心算法。"相对于 Kruskal，Prim 更适宜于稀疏图"——错误，方向记反是送分变丢分。

四、拓展与图应用（PAGE 55-81）课件拓展·408不考

  • MST 唯性（PAGE 55 思考）：边权互异则 MST 唯一；有权值相同的边时不一定不唯一。最大支撑树=权取反；最小乘积支撑树=权取对数。

  • 应用拓展（PAGE 68-81）：PageRank（PR 值沿出度分配迭代）；智能拼音输入法（句子的最大概率⟺ -log 概率为权的最短路）；神经元 y=σ(Σwᵢxᵢ+b) 与多层网络；贝叶斯网络。MST 还用于聚类（Kruskal 跑到剩 k 个分量）与图像分割。

void ShellSort(int R[], int n) {          // d1=n/2 递减到1
    for (int d = n / 2; d > 0; d /= 2)
        for (int i = d + 1; i <= n; i++) {
            int K = R[i], j = i - d;
            while (j > 0 && R[j] > K) { R[j + d] = R[j]; j -= d; }  // 组内插入

}

L18 · 堆排序408高频考点必考模板

本节导入：直接选择每趟找最大要 O(n)，重复比较太浪费——能不能用树形结构把比较结果存起来？先看锦标赛排序（胜者树）（PAGE 6-11）：取冠军 O(n)，之后每次把冠军叶改 −∞ 重赛只要 O(logn)，总 O(nlogn)——但至少 2n−1 个结点，拿空间换时间。更省的方案：把树隐含在数组里——堆。

一、堆的定义与存储（PAGE 13-20）

📌【PPT课堂重点】堆的两性质（PAGE 16-19）
最大堆（大根堆）= 完全二叉树 + 任意结点 ≥ 其两孩子——①结构性（完全二叉树）②堆序性；最小堆相反；根是最大/最小是堆的优势。顺序存储：R[1] 存根，R[i] 左孩子 R[2i]、右孩子 R[2i+1]、父 R[⌊i/2⌋]。

二、上浮与下沉（PAGE 23-43）

  • 上浮 ShiftUp（元素变大，插入用）：与父比、大于父交换、i/=2，至根或不大于父。O(logn)。
  • 下沉 ShiftDown（元素变小，核心操作）：与最大孩子比较（先两个孩子比一次、再与自身比一次，共2次比较）、小于则交换下移；循环条件 i≤n/2。O(logn)。
void ShiftDown(int R[], int n, int i) {       // 与最大孩子比较
    while (i <= n / 2) {                      // 最多到最后一个非叶结点
        int maxchd = 2 * i;
        if (maxchd < n && R[maxchd] < R[maxchd + 1]) maxchd++;  // 选大孩子
        if (R[i] > R[maxchd]) return;
        swap(R[maxchd], R[i]);
        i = maxchd;
    }
}
void BuildHeap(int R[], int n) {              // Floyd自底向上建堆
    for (int i = n / 2; i >= 1; i--)         // 从最后一个非叶结点开始
        ShiftDown(R, n, i);
}
void HeapSort(int R[], int n) {
    BuildHeap(R, n);                          // ①建大根堆
    for (int i = n; i > 1; i--) {             // ②n-1趟
        swap(R[1], R[i]);                     // 堆顶(最大)换到末尾就位
        ShiftDown(R, i - 1, 1);               // 剩余堆规模i-1，下沉重建
    }
}
📌【PPT课堂重点】自底向上建堆是 O(n)，不是 O(nlogn)！（PAGE 44-55）
各结点下沉代价≤其高度，总代价=高度和 T=n/4·1 + n/8·2 + n/16·3 + …，错位相减得 T<n。清华考研判断题"建堆至少需O(nlogn)"为错误（PAGE 57）。
堆排序：最好=平均=最坏 O(nlogn)、空间 O(1)、不稳定——"虽然操作的是数组，但背后隐藏的灵魂是二叉树"（PAGE 71）。大根堆排升序（最大不断沉底）；要降序建小根堆。

三、堆与优先级队列（PAGE 88-112）

L19 · 快速排序408高频考点必考模板

本节导入：Hoare 1960 年提出、IEEE 20世纪十大算法之一。它的地位：基于关键词比较的内排序中平均时间最快。

一、基本思想与 Partition（PAGE 4-25）

📌【PPT课堂重点】一趟分划，一个元素就位（PAGE 4-9）
选基准 K（轴点 Pivot，如 R[m]），使左侧子数组 ≤K、右侧 >K、K 居中就位，再对两半递归——分治法。操作①就是 Partition：
指针 L 从左向右找第一个 >K（"喜欢小讨厌大"）、G 从右向左找第一个 ≤K，交换 R[L]、R[G]，直至相遇；最后 swap(R[m], R[G])。特点：一趟分划把一个记录放在最终位置上——这是判断"某序列是否快排一趟结果"的依据！G 扫描不需考虑左越界（基准 K 在 R[m] 兜底）。 
int Partition(int R[], int m, int n) {     // [m, n]，基准R[m]
    int K = R[m], L = m + 1, G = n;
    while (L <= G) {
        while (L <= n && R[L] <= K) L++;   // 从左找 >K
        while (R[G] > K) G--;                // 从右找 <=K（左边有K兜底）
        if (L < G) { swap(R[L], R[G]); L++; G--; }
    }
    swap(R[m], R[G]);                       // 基准归位，返回其位置
    return G;
}
void QuickSort(int R[], int m, int n) {
    if (m < n) {
        int j = Partition(R, m, n);
        QuickSort(R, m, j - 1);
        QuickSort(R, j + 1, n);
    }
}

  4. 尾递归转循环——最坏空间仍 O(n)；
  5. 尾递归+先处理短区间——递归深度降为 O(logn)（每次子问题至少减半）；注意它只降空间、不能把最坏时间降到 O(nlogn)；
  6. 用栈消除全部递归（栈存区间二元组）；
  7. 侦测递归深度达 O(logn) 层时转堆排序——真正使最坏时间为 O(nlogn)，即 Introsort 内省排序（C++ STL sort 的做法：≤16转插入+超深转堆排）；
  8. 三路分划（重复元素多时 <K/=K/>K 三段，只递归左右）——即荷兰国旗问题（Dijkstra）：三指针 i/j/k，j 遍历：红则换入左区 i++、j++；蓝则换入右区 k−−（不 j++，换来的没检查过）；白则 j++。

为什么快排平均比堆排快（PAGE 69-71）：①nlogn 的常系数小；②访问物理相邻数据缓存命中率高（堆排跳访 R[i]→R[2i]）。缓存友好写法（PAGE 72-77）：二维数组按行遍历、矩阵乘法 i-k-j 序。

四、快速选择 QuickSelect 与 BFPRT（PAGE 79-92）

找第k小（PAGE 79-83）：Partition 后左段个数 nL：nL==k−1 则 R[j] 即答案；nL>k−1 在左段找第k小；nL<k−1 在右段找第 k−nL−1 小——只递归一侧=减治法，最好/平均 O(n)（n+n/2+…≤2n），最坏 O(n²)。BFPRT（中位数的中位数，PAGE 84-90）课件拓展·408不考：5个一组取各组中位数、再取中位数作基准，保证分划最差3:7，理论最坏 O(n)——但常数大实际很少用。TopK：快选 vs 堆——数据是静态的快选好；增量数据用堆（新元素堆只要 O(logk)，快选要重做 O(n)）。

L20 · 归并排序与比较排序下界408高频考点必考模板

一、Merge 与归并排序（PAGE 4-23）

📌【PPT课堂重点】（PAGE 4-23）
Merge：合并相邻有序段 R[low..mid]、R[mid+1..high]：i、j 扫描取小放 X[k]——相等时先放左(i)侧（稳定性的来源！）；一方扫完另一方整段拷入；再拷回 R。O(n) 时间、O(n) 辅助数组。
递归版：分治——对半递归再 Merge，递归树 logn 层×每层 O(n) → 三态全 O(nlogn)、空间 O(n)、稳定——"最快的稳定性排序算法"。
非递归（自底向上）：for(L=1; L<n; L*=2) 相邻长度 L 的段两两合并（尾部残余单独处理）——趟数 logn。 
void Merge(int R[], int low, int mid, int high) {    // 借助辅助数组X
    int i = low, j = mid + 1, k = 0;
    int *X = new int[high - low + 1];
    while (i <= mid && j <= high)
        if (R[i] <= R[j]) X[k++] = R[i++];   // 相等先放左 → 稳定
        else               X[k++] = R[j++];
    while (i <= mid)  X[k++] = R[i++];
    while (j <= high) X[k++] = R[j++];
    for (k = 0, i = low; i <= high; ) R[i++] = X[k++];
    delete[] X;
}
void MergeSort(int R[], int n) {              // 自底向上
    for (int L = 1; L < n; L *= 2)            // 段长逐趟翻倍
        MergePass(R, n, L);                   // 相邻长度L的段两两合并
}

逆序对（PAGE 26-29，面试高频）：Merge 中当 R[i]>R[j] 时，R[i..mid] 都 >R[j]——cnt += mid−i+1，各次 Merge 累计 O(nlogn)。分治对比（PAGE 30）：快排侧重"分"（合无需操作），归并侧重"合"（分即对半）。优化（PAGE 24）：小数据转插入；元素很大时改链表存储（移动变指针）。

二、比较排序的下界（PAGE 38-47）课件拓展·408不考（结论常被引用）

判定树：n 个元素的每种排列（n! 种）对应一个叶子；一种输入的比较次数=根到叶路径长度；判定树高度=最坏比较次数。由 n!≤2^h 得 h≥log₂(n!)，而 log(n!) ≥ (n/2)·log(n/2) = Ω(nlogn)。结论：任何基于关键词比较的排序，最坏（和平均）比较次数至少 Ω(nlogn)——这就是堆排/归并/快排平均"封顶"的理论原因；分布排序不受此限（下一讲）。

三、外排序一瞥（PAGE 49-52）

文件远大于内存时：分块读入、内排序成多个有序块、多路归并成大文件。10TB 数据排序选归并（考研题，PAGE 52）。408 新大纲的外排序（多路归并/败者树/最佳归并树）需另行补充，课件只到原理。

一、桶排序（PAGE 4-23）

值域 [0,m) 设 m 个桶：①分配——扫描元素按关键词入桶；②收集——依次取出各桶元素。桶用链式队列实现，同桶先进先出 → 稳定。O(n+m)，m=O(n) 时线性。

二、计数排序（PAGE 25-41）

📌【PPT课堂重点】计数三步（PAGE 26-31）
①扫描计数 cnt[R[i]]++；②前缀和 cnt[i]+=cnt[i−1]——此时 cnt[i]=R 中 ≤i 的元素个数=元素 i 在有序数组中的位置；③从右往左扫描：B[cnt[R[i]]−−]=R[i]——必须从右往左才稳定（同值元素右侧者进高位槽）！O(n+m)、稳定。

三、基数排序（PAGE 43-94）——408 在纲

📌【PPT课堂重点】LSD 逐位稳定排序（PAGE 44-45）
关键词由多域构成 K=(K_d,…,K_2,K_1)：自 K1（最低位）至 Kd 依次以各域做"稳定排序"——每位是 [0,r) 内整数，用桶或计数排序实现。每趟必须稳定（LSD 正确性的来源；某趟不稳定结果就错）。时间 O(d(n+r))、空间 O(n+r)、稳定；d=位数、r=基数，d、r 为常数时线性；适合位数固定/可拆分的关键词。 
void CountingSort(int R[], int n, int m, int B[]) {   // 值域[0,m)
    int cnt[M] = {0};
    for (int i = 1; i <= n; i++) cnt[R[i]]++;              // ①计数
    for (int i = 1; i < m; i++) cnt[i] += cnt[i - 1];     // ②前缀和=排名
    for (int i = n; i >= 1; i--) B[cnt[R[i]]--] = R[i];   // ③从右往左放
}

L22 · 线性结构查找408高频考点

本节导入：查找（检索）：给定值 K，在含 n 个记录的文件中找关键词等于 K 的记录，分成功/失败。ASL（平均查找长度）=查找一个元素的关键词平均比较次数——衡量查找算法优劣的主要标准（PAGE 3）。这一讲的方法串成一条线：用不同规则确定 mid，得到不同方法：对半、斐波那契、插值（PAGE 6）。

一、顺序查找与对半查找（PAGE 4-27）

顺序查找无序表 O(n)。对半（折半）查找：mid=⌊(low+high)/2⌋，每轮淘汰一半，O(logn)。对半插入排序（PAGE 9）：插入位置用对半定——比较次数降到 O(logn)，但移动次数不变，总时间仍 O(n²)（常系数更小）。

📌【PPT课堂重点】判定树与 ASL 口径（PAGE 19-25，期末408双考）
对半查找的二叉判定树是扩充二叉树（空指针处加方形外结点）。成功查找对应内结点：比较次数=结点深度+1；失败对应外结点：比较次数=该外结点深度（根到它经过的内结点数）。
ASL_succ = (1/n)Σ(深度+1)；ASL_unsucc = (1/(n+1))Σ(外结点深度)——失败的分母是 n+1（外结点个数），不是 n！

二、斐波那契查找与插值查找（PAGE 29-46）课件拓展·408不考

  • 斐波那契查找：设 n=F_k−1，比较 R[F_{k−1}]：小则左段（F_{k−1}−1，k−1阶）、大则右段（F_{k−2}−1，k−2阶）——黄金分割 0.618 划分；O(log₂n) 但总体略快于对半（进左只比1次的概率大），且只用加减不用乘除；n 不是 F_k−1 时用 R[n] 补全、返回下标要截断 (mid<n)?mid:n。

二、AVL 高度平衡树（PAGE 46-93）

定义（PAGE 48-49）：任一结点左右子树高度至多差1；平衡系数=左高−右高 ∈ {−1,0,1}。高度（PAGE 52-53）：最少结点 F(0)=1、F(1)=2、F(h)=F(h−1)+F(h−2)+1；精确上界 h ≤ 1.4404·log₂(n+2) − 0.3277（最多比满树高44%）。

📌【PPT课堂重点】四种失衡与旋转（PAGE 57-87，期末408年年考）
型判别（新结点插入路径）调整（口诀：左子树高右转、右子树高左转）
LL左孩子的左侧单旋转右转：抓B上提，A成B右孩子，B的BR挂A左
RR右孩子的右侧单旋转左转（镜像）
LR左孩子的右侧双旋转：先对左子树做RR（以C为轴左转B）再LL（右转A）：LR(A){RR(A->left); LL(A);}
RL右孩子的左侧双旋转：先对右子树做LL再RR：RL(A){LL(A->right); RR(A);}
插入：找"从插入点到根路径上第一个失衡结点A"，平衡以A为根的最小子树；旋转后子树高度与插入前相同（h+1）→ 插入最多2次旋转（一次单旋或一次双旋）。
删除：平衡后子树高度可能变小 → 失衡可连锁上传直至根，最坏 O(logn) 次旋转（对比插入 O(1) 次）。 
int Height(AVLnode* t);
void UpdateHeight(AVLnode* t) { t->height = max(Height(t->left), Height(t->right)) + 1; }
void Balance(AVLnode *&t) {                  // 回溯时逐层调用
    UpdateHeight(t);
    if (Height(t->left) - Height(t->right) == 2)          // 左高
        if (Height(t->left->left) >= Height(t->left->right)) LL(t);
        else LR(t);
    else if (Height(t->right) - Height(t->left) == 2)     // 右高
        if (Height(t->right->right) >= Height(t->right->left)) RR(t);
        else RL(t);
}
void Insert(AVLnode *&root, int K) {         // 递归插入，返回路上逐层Balance
    if (root == NULL) { root = new AVLnode(K); return; }
    if (K < root->key) Insert(root->left, K);
    else if (K > root->key) Insert(root->right, K);
    Balance(root);
}

三、红黑树与伸展树（PAGE 95-112）

📌【PPT课堂重点】红黑树五性质（2022年起408入纲，PAGE 95-98）
①非红即黑；②根黑；③外结点黑；④红父黑子（红结点孩子必黑）；⑤任一结点到其每个外结点的路径含相同数目黑结点（黑高相等）。推论：忽略红结点则平衡，最长路径≤最短2倍，h≤2logn；插/删/查最坏 O(logn) 且最多3次旋转。与AVL取舍：平衡略弱、查找略慢，但增删失衡概率小、增删更快。应用：Linux CFS调度、C++ STL map/set 基于 红黑树、Java TreeMap。

伸展树 Splay（PAGE 100-108）课件拓展·408不考：基于时间局部性——每次访问 X 后把它旋转到根；三种情况（一字型先转爷再转父、之字型同AVL双旋、只有父单转）；各操作均摊 O(logn)。

⚠️【PPT易错提醒】
BST 遇重复关键词不再插入；两孩子删除用中根后继（右子树最左）替换，不是直接拿右孩子；递归 Insert 必须引用参数 &root（或返回新根），否则修改不生效（PAGE 34-37 的 increase 类比）；LR/RL 双旋的先后次序（LR先动左子树）易混。

本节小结：本节课我们重点掌握了——BST 中序有序性与删除三情况；BST 最坏退化 O(n)；AVL 平衡系数、四型旋转判定与口诀、插入最多2次旋转 vs 删除最坏 O(logn) 次；最少结点递推 F(h)；红黑树五性质与"最多3次旋转、h≤2logn"（2022入纲）；伸展树均摊 O(logn) 作拓展。

一、m 阶 B 树（PAGE 8-46）

📌【PPT课堂重点】m阶B树五条定义（PAGE 10，必须逐字掌握）
①每个结点至多 m 个子结点；②除根外每个非叶结点至少 ⌈m/2⌉ 个子结点；③根若非叶至少 2 个子结点；④有 k 个子结点的结点恰有 k−1 个递增有序关键词；⑤所有叶结点（失败结点）在同一层且不带信息。
换算（7阶例）：非根 3~6 个关键词、根 1~6 个。查找（PAGE 13-14）：结点内顺序/对半查找 K，不在则沿 Ki~Ki+1 之间的指针把子结点读入内存继续；指针空则失败。
高度（PAGE 45-46）：n 个关键词有 n+1 个叶结点（n种成功、n+1种失败查找）；k ≤ 1 + log_{⌈m/2⌉}((n+1)/2) = O(log_m n)。m 的选取≈一个磁盘块（数据库常用 m=200~300，n=2×10¹⁰ 时至多5次外存访问）。
📌【PPT课堂重点】插入分裂与删除三步（PAGE 15-44，大题题源）
插入：未满（<m−1 个）直接插；已满上溢分裂：第 ⌈m/2⌉ 个关键词提升到父结点，左右各成新结点；分裂可逐层上传直至根（树长高、根分裂是树长高的唯一方式）。
删除口诀："先换后删、下溢借位、不够借则合并"：①非最底层的 K 先与右子树最底层最小（中根后继）交换，使真正删除只发生在最底层；②删后关键词 <⌈m/2⌉−1（下溢）向兄弟借：经父结点中转（兄弟的上移、父的分隔词下移），"左顾右盼"优先左兄弟；若借位不在最底层，须连子树一起借；③兄弟也不够借（恰为⌈m/2⌉−1）则两兄弟+父结点分隔词合并（优先左），合并可能使父下溢、上传，可能使树降一层。

二、冲突处理（PAGE 17-30）

  • 开散列=拉链法：同地址记录链成单链表，T[i] 头指针；链太长可换跳表/查找树（unordered_map/HashMap 思想，Java 链长>8 转红黑树）。
  • 闭散列=开放地址法：线性探查 hᵢ=(h(K)+i)%M——缓存命中率高，缺点聚集；二次探查 hᵢ=(h(K)±i²)%M（+1²,−1²,+2²,−2²…交替）更快跳离冲突区；双重探查步长 δ(K) 与 K 相关，δ(K) 与 M 互质（故 M 取素数）才能探遍全表。
  • 装填因子 α=N/M：实用 0.5~0.8（Java 0.75 自动扩容；STL 默认1.0可改）。

三、闭散列的删除（PAGE 32-43）

📌【PPT课堂重点】闭散列不能直接删除（PAGE 32-33）
该位置可能被别人的探查路径经过，直接清空会阻断查找（删位置1后查 21、31、51 全失败）。三方案：①懒惰删除——位置三状态（空/占用/已删除），查找跳过、插入可复用，缺点空位越来越少；②实时删除——清空 T[j] 后考察 j+1 到下一空位前的每个 i：若清空阻断了"从 h(T[i]) 探查到 i"的路径则前移（最坏O(n)，α≤2/3 时平均O(1)）；③延迟删除——平时懒惰、定期按访问频次降序重建（热点靠近散列地址降 ASL）。②③为课件拓展。
