0. 应试须知：STL 考场可用边界 + 四大应试模块总览高频考点

🎬 对应课程：L26 考试规则（STL 使用边界的老师原话）+ L1/L2 绪论 ｜ 考试规则见 L0/L26

  • 红线（考场禁用STL）：题目考察的数据结构/算法本身必须手写——考链表必须写链式结构与指针操作（禁用 std::list）；考排序必须写排序过程（禁用 sort）；考哈希表必须写散列函数与冲突处理（禁用 unordered_map）。

  • 机试放开：复试机试/刷题平台STL是提分利器，第七部分真题代码全部放开使用。

1. vector —— 动态数组机试可用笔试需声明高频考点

🎬 对应课程：L5 数组与矩阵（顺序存储在慕课/教材）；机试首选容器 ｜ 考试规则见 L0/L26

应试定位：逻辑上就是顺序表。笔试作答顺序表按SqList手写；机试中vector是第一工具容器。

🔗 王道考点联动：第2章 顺序表的定义与操作 —— 顺序表按位存取O(1)、插删O(n)的原理。原理精讲见王道精讲页对应小节。

核心定义：连续内存的动态数组，O(1)随机访问、尾部均摊O(1)插删、自动扩容。下标从0起，v[i]不做越界检查。适用：随机访问多、尾部增删、做邻接表/DP表。禁用：频繁头部/中间插删（O(n)，应换list/deque）。

常用接口

接口原型功能/用法返回值复杂度
vector<int> v(n, 0);n个0；vector<int> w(v)拷贝；二维vector<vector<int>> g(n);—O(n)
v.push_back(x) / v.pop_back()尾插（可能扩容）/ 尾删void均摊O(1)
v[i] / v.at(i)随机访问；at越界抛异常引用O(1)
v.front() / v.back()首/尾元素引用O(1)
v.insert(v.begin()+i, x)下标i前插入，其后整体后移新位置迭代器O(n)
v.erase(v.begin()+i)删除下标i元素；返回下一个有效迭代器迭代器O(n)
v.size() / v.empty() / v.clear()逻辑长度/判空/清空（capacity不一定变）见名O(1)/O(1)/O(n)
v.resize(n) / v.reserve(n)改逻辑长度（真正生成元素）/仅预留容量voidO(n)
v.begin() / v.end()首元素/尾后位置（左闭右开）迭代器O(1)
高频易错点：① size是逻辑长度、capacity是物理容量，reserve不改size；② 扩容使全部迭代器失效，insert/erase使操作点之后失效；③ 循环删除必须it = v.erase(it)；④ v[i]越界是未定义行为。
访问 O(1)尾部插删 均摊O(1)中间插删 O(n)查找 O(n)
【例1·基础用法题】

写出下面代码的输出：vector<int> v; v.reserve(10); v.push_back(1); v.push_back(2); cout << v.size() << " " << v.capacity();

查看解析

输出 2 10。reserve只改容量（≥10），size只统计实际元素（2）。若把reserve换成resize(10)，输出为 10 10，且遍历会多出8个0——两者区别是笔试/机试双重坑。

【例2·408风格应用题】

顺序表用 vector<int> v 存储长度n。设计O(n)、O(1)算法将其逆置，并说明能否直接调 reverse(v.begin(), v.end())。

查看解析
void Reverse(vector<int> &v) {
    int i = 0, j = v.size() - 1;
    while (i < j) {
        swap(v[i], v[j]);    // 首尾交换，向中间推进
        i++; j--;
    }
}

等价。std::reverse内部就是首尾双指针交换，O(n)/O(1)。笔试若逆置非考察点可写「调用reverse，O(n)」；是考察点则按上式手写。

2. string —— 字符串机试可用笔试多手写高频考点

🎬 对应课程：L6 字符串模式匹配（KMP 必须手写；string 是机试载体） ｜ 考试规则见 L0/L26

应试定位：串的顺序存储。KMP/BF模式匹配必须手写；string是机试串题载体。

🔗 王道考点联动：第4章 串的定义与KMP模式匹配 —— 串的顺序存储、BF与KMP手写考点。原理精讲见王道精讲页对应小节。

核心定义：可变长字符串，用法近vector，另支持+拼接与字典序直接比较。适用：机试读串/拆词/匹配。禁用：笔试考KMP的next数组计算——那是手写考点，string只是载体。

常用接口

接口原型功能/用法返回值复杂度
s.size() / s.length()串长无符号整型O(1)
s.substr(pos, len)取子串（len缺省到结尾）；pos越界抛异常stringO(len)
s.find(t)找子串/字符首次出现位置下标；无则 string::nposO(n·m)

s.push_back(c) / s.append(t)尾插字符 / 尾接串void均摊O(1)

s.c_str() / to_string(x) / stoi(s)转C串 / 数字转串 / 串转数字指针/string/intO(1)/O(logx)/O(n)

随机访问 O(1)find O(n·m)拼接/插删 O(n)
【例1·基础用法题】

统计字符串s中子串"ab"出现的次数（允许重叠）。

查看解析
int cnt = 0, pos = s.find("ab");
while (pos != string::npos) {
    cnt++;
    pos = s.find("ab", pos + 1);   // 从下一位置继续找（允许重叠）
}

考点：find的第二参数（起始位置）与npos判等。

【例2·408风格应用题】

设计O(n)、O(1)算法判断只含小写字母的串s是否回文。

查看解析
bool isPalindrome(const string &s) {
    int i = 0, j = s.size() - 1;
    while (i < j) {
        if (s[i] != s[j]) return false;
        i++; j--;
    }
    return true;
}

考点提炼：首尾双指针。408变体"回文链表"：快慢指针找中点+后半段逆置（LC234，见第七部分）。

3. deque —— 双端队列机试可用笔试须手写

🎬 对应课程：L4 队列（课件用手写循环队列，见第四部分2.2） ｜ 考试规则见 L0/L26

应试定位：笔试考"输出受限/输入受限双端队列的合法序列判断"（逻辑结构选择题）；STL deque是机试单调队列的标准载体。

🔗 王道考点联动：第3章 双端队列 —— 输出/输入受限双端队列合法序列判断。原理精讲见王道精讲页对应小节。

核心定义：两端均O(1)插删、支持O(1)随机访问的队列（分段连续，原理不深究）。适用：滑动窗口、两端操作。禁用：笔试写循环队列时用手写数组版更稳。

常用接口

接口原型功能/用法返回值复杂度
d.push_back(x) / d.push_front(x)尾插 / 头插voidO(1)
d.pop_back() / d.pop_front()尾删 / 头删voidO(1)
d.front() / d.back()队头 / 队尾元素引用O(1)
d[i]随机访问引用O(1)
d.size() / d.clear() / d.insert / erase长度 / 清空 / 中间插删（全部迭代器失效）见名O(1)/O(n)/O(n)
高频易错点：①中间插删使所有迭代器失效；②STL deque（两端可进出）≠考纲"输出受限双端队列"（一端只能删）——后者是逻辑结构选择题；③408笔试的单调队列用手写数组模拟（见第四部分2.4）。
两端插删 O(1)随机访问 O(1)中间插删 O(n)
【例1·基础用法题】

用deque实现"读入n个整数，从右往左倒序输出"。

查看解析
deque<int> d;
for (int i = 0; i < n; i++) { int x; cin >> x; d.push_front(x); }  // 头插即倒序
for (int x : d) cout << x << " ";
【例2·408风格选择题】

输出受限的双端队列（两端可插、只能一端删），输入1,2,3,4，判断输出序列 4,1,3,2 是否可能。（2010年真题同型）

查看解析

可能。设右端可删：4右插→4右删；1右插→1右删；3右插、2左插→3右删→2右删，得 4,1,3,2 ✔。方法就是手动模拟：每步分支"插左还是插右"。

4. list —— 双向链表机试可用笔试须手写

🎬 对应课程：L3 线性表的链接存储（考链表必须手写 LinkList，禁用 std::list 作答） ｜ 考试规则见 L0/L26

应试定位：考链表必手写LinkList；list用于机试快速模拟（约瑟夫环等）。

🔗 王道考点联动：第2章 双链表与链式存储 —— 链表结点、双向指针操作。原理精讲见王道精讲页对应小节。

核心定义：双向链表，已知迭代器位置插删O(1)，不支持随机访问（无[]）。自带成员 sort()（归并、稳定），因为std::sort需要随机访问迭代器。适用：频繁任意位置插删、splice拼接。禁用：频繁按下标访问（O(n)）。

常用接口

接口原型功能/用法返回值复杂度
l.push_back(x) / l.push_front(x)尾插 / 头插voidO(1)
l.insert(it, x)it之前插入新元素迭代器O(1)
l.erase(it)删除it处元素下一个有效迭代器O(1)
l.remove(x)删除所有等于xvoidO(n)
l.sort() / l.reverse() / l.unique()成员排序（稳定归并）/逆置/相邻去重voidO(nlogn)/O(n)/O(n)
l.splice(pos, other)O(1)搬移结点拼接（list特有）voidO(1)
l.front() / l.back() / l.size()首尾元素 / 长度引用 / 整数O(1)
高频易错点：①不能用std::sort（随机访问迭代器），只能 l.sort()；②erase后接返回值继续遍历；③下标访问不存在——要随机访问请用vector。
已知位置插删 O(1)定位 O(n)空间 每结点多2指针
【例1·基础用法题】

对list降序排序并删除所有值为5的元素。

查看解析
l.sort();                    // 成员排序（不能用std::sort！）
l.sort(greater<int>());      // 降序：传入比较器
l.remove(5);                 // 删除所有5
【例2·408风格应用题】

n人围成一圈报数，报到m者出列，求出列序列（约瑟夫问题）。用list实现。

查看解析
list<int> l;
for (int i = 1; i <= n; i++) l.push_back(i);
list<int>::iterator it = l.begin();
while (!l.empty()) {
    for (int k = 1; k < m; k++) {          // 报数走m-1步
        if (++it == l.end()) it = l.begin();   // 环形回绕
    }
    cout << *it << " ";
    it = l.erase(it);                       // erase返回下一个位置
    if (it == l.end()) it = l.begin();
}

笔试作答：手写循环单链表（尾结点next指向首元结点），思想一致。

5. set / multiset —— 有序集合机试可用笔试须手写高频考点

🎬 对应课程：L23 二叉查找树（set/map 底层即红黑树，L23 PAGE 110-112） ｜ 考试规则见 L0/L26

应试定位：逻辑上是BST/平衡树的应用。笔试考BST、AVL必手写；set是机试"有序+去重+前驱后继"神器。

🔗 王道考点联动：第7章 二叉排序树与有序查找 —— set底层红黑树=有序集合，中序遍历有序。原理精讲见王道精讲页对应小节。

核心定义：红黑树实现（记住"有序+对数操作"即可）。set自动升序+去重；multiset允许重复。适用：去重、动态有序集合、前驱后继、区间统计。禁用：无需有序、只要判定存在——用unordered_set更快。

常用接口

接口原型功能/用法返回值复杂度
s.insert(x)插入；set已存在则失败pair<迭代器,bool>O(logn)
s.erase(x) / s.erase(it)按值删（multiset删全部）/按位置删个数/voidO(logn)
s.find(x) / s.count(x)查找 / 计数（set只会0/1）迭代器（无则end）/size_tO(logn)
s.lower_bound(x) / s.upper_bound(x)第一个≥x / 第一个>x（成员版）迭代器O(logn)
s.begin() / s.rbegin()最小 / 最大元素位置迭代器O(1)
s.size() / s.empty() / s.clear()长度/判空/清空见名O(1)
高频易错点：①multiset的 erase(x) 删所有等于x的元素，只删一个要 erase(s.find(x))；②set迭代器只读，不能 *it = ...；③前驱/后继 = prev(it) / next(it)（保证迭代器合法）；④自定义类型需提供比较器。
插/删/查 O(logn)遍历 有序O(n)
【例1·基础用法题】

依次 insert(3,1,2,3,5) 到set与multiset，再对multiset执行erase(3)，分别写出遍历结果。

查看解析

set：size=4，输出 1 2 3 5（自动去重升序）。multiset：erase(3)删掉两个3，输出 1 2 5；只删一个应写 ms.erase(ms.find(3))。

【例2·408风格应用题】

动态集合支持插入、删除、查询前驱/后继，要求单步O(logn)。给出set解法骨架。

查看解析
set<int> s;
s.insert(x);                        // O(logn)
s.erase(s.find(x));                 // 只删一个
set<int>::iterator it = s.lower_bound(x);   // 首个>=x
if (it == s.begin()) /* 无前驱 */; else /* *prev(it)即前驱 */;
it = s.upper_bound(x);                      // 首个>x
if (it != s.end()) /* *it即后继 */;

完整题见第六部分·实战 e6 与第七部分对应set模块。unordered_set没有lower_bound——有序性不可替代。

6. map / multimap —— 有序键值对机试可用笔试须手写高频考点

🎬 对应课程：L23 红黑树（STL map 基于⽭红黑树）+ L22 有序查找 ｜ 考试规则见 L0/L26

应试定位：对应"查找表/索引"。笔试考散列表、BST必手写；map是机试映射计数第一选择。

🔗 王道考点联动：第7章 查找结构 —— map=关键字有序查找表。原理精讲见王道精讲页对应小节。

核心定义：按key升序的键值对容器（红黑树）。value可重复、key唯一（multimap的key可重复）。适用：计数、编号映射、有序统计。禁用：不需要有序时用unordered_map更快。

常用接口

接口原型功能/用法返回值复杂度
m[k]取value；k不存在则自动插入(k,默认值)引用O(logn)
m.at(k)只取不插；不存在抛异常引用O(logn)
m.insert({k, v})插入；k已存在则失败（不覆盖）pair<迭代器,bool>O(logn)
m[k] = v赋值/覆盖（不存在先插入）引用O(logn)
m.find(k) / m.count(k) / m.erase(k)查找/计数/按键删见名O(logn)
遍历 for (auto &p : m)p.first为key（const）、p.second为value，按key升序—O(n)
高频易错点：① operator[]的副作用：只读判断也用m[k]会插入默认值，改变size与遍历——判断存在性一律用 find/count；② m[k]=v覆盖、insert不覆盖；③ multimap没有operator[]。
插/删/查 O(logn)遍历 按key升序O(n)
【例1·基础用法题】

查看解析

无输出，size=2。m['c']的语义是"不存在则插入('c',0)再返回"——副作用插入了新键。正确只读写法：auto it=m.find('c'); if (it!=m.end() && it->second>0)。

查看解析

sort 三种典型用法

#include <algorithm>
using namespace std;

struct Stu { int id; int score; };
bool cmpScore(const Stu &a, const Stu &b) { return a.score > b.score; }   // 函数比较器：成绩降序
bool cmpMulti(const Stu &a, const Stu &b) {                               // 多关键字：成绩降序，同分id升序
    if (a.score != b.score) return a.score > b.score;
    return a.id < b.id;
}

int main() {
    vector<int> v = {3, 1, 4, 1, 5};
    sort(v.begin(), v.end());                     // 1 1 3 4 5 升序
    sort(v.begin(), v.end(), greater<int>());     // 5 4 3 1 1 降序
    sort(v.begin(), v.end(), [](const Stu &a, const Stu &b) { return a.score > b.score; });  // lambda
    return 0;
}
高频易错点：①cmp必须满足严格弱序：相等时返回false，写成 >= 可能运行崩溃；②不稳定——需要保序换 stable_sort；③list不能用std::sort；④数组同样适用 sort(a, a+n)。
sort O(nlogn) 不稳定stable_sort O(nlogn) 稳定 空间O(n)

查看解析

cmp见上方 cmpMulti。>=违反严格弱序：相等元素互相返回true，sort内部可能越界崩溃。规则：相等必须返回false。

11. reverse（逆置）必考模板

🔗 王道考点联动：第2章 顺序表逆置 —— 首尾双指针原地交换。原理精讲见王道精讲页对应小节。

🎬 对应课程：L17 插入排序思想的逆置版；L3 双指针 ｜ 考试规则见 L0/L26

原型：void reverse(BidirIt first, BidirIt last); 逆置 [first, last)，原地双指针交换，O(n)/O(1)。

参数与返回值：两个双向迭代器（end是尾后不参与）；无返回值，原地修改。vector/string/数组/list均可。

vector<int> v = {1, 2, 3, 4, 5};

应试注意：2010年真题「数组循环左移p位」最优解=三次逆置法，机试三行reverse搞定；笔试需手写逆置函数（见例2）。

【例1·基础用法题】

把字符串s按单词逆序输出（单词间空格分隔），用reverse+双指针实现。

查看解析
reverse(s.begin(), s.end());            // 整体逆置
int i = 0;
while (i < (int)s.size()) {
    int j = i;
    while (j < (int)s.size() && s[j] != ' ') j++;
    reverse(s.begin() + i, s.begin() + j);   // 每个单词再逆回来
    i = j + 1;
}
【例2·408真题风格应用题】

n个整数存于数组R，设计时间空间均最优的算法，将R循环左移p位。（2010年真题）

查看解析

三次逆置法：逆前p个→逆后n-p个→整体逆置。例：1,2,3,4,5左移2 → 2,1,3,4,5 → 2,1,5,4,3 → 3,4,5,1,2。

void Reverse(int R[], int l, int r) {
    for (int i = l, j = r; i < j; i++, j--) {
        int t = R[i]; R[i] = R[j]; R[j] = t;
    }
}
void LeftShift(int R[], int n, int p) {
    Reverse(R, 0, p - 1); Reverse(R, p, n - 1); Reverse(R, 0, n - 1);
}

O(n)/O(1)。机试三行：reverse(a,a+p); reverse(a+p,a+n); reverse(a,a+n);（LC189 轮转数组同源，见第七部分）。

【例2·408真题风格应用题】

求n个整数的"主元素"（出现次数超过n/2者），时间尽量优。

查看解析

摩尔投票：同则cnt++、异则cnt--，减到0换候选；最后用count验证候选。

int Majority(int a[], int n) {
    int cand = a[0], cnt = 1;
    for (int i = 1; i < n; i++) {
        if (a[i] == cand) cnt++;
        else if (--cnt == 0) { cand = a[i]; cnt = 1; }
    }
    return count(a, a + n, cand) > n / 2 ? cand : -1;   // 第二趟验证O(n)
}

O(n)/O(1)，笔试写明"调用线性计数O(n)"即可。

🎬 对应课程：L22 对半查找（BinSearchFirstPosGEK 返回 low 即 lower_bound 语义） ｜ 考试规则见 L0/L26

原型：ForwardIt lower_bound(first, last, x);　ForwardIt upper_bound(first, last, x);

语义（必背）：在非降序区间上二分：lower_bound返回第一个≥x的位置；upper_bound返回第一个>x的位置；不存在返回last。O(logn)。

用途写法
下标换算int pos = lower_bound(a, a+n, x) - a;（pos==n表示x比全部都大）
x是否存在pos != n && a[pos] == x
x出现次数upper_bound(...) - lower_bound(...)
有序插入位置lower_bound结果即插入点
set/map成员版s.lower_bound(x)（O(logn)；set无序禁用全局版）
最大坑点：对无序区间调用结果是未定义的（不报错但结果错）。笔试的折半查找（判定树/ASL）必须手写，见第四部分5.1。
时间 O(logn)前提 区间非降序
【例1·基础用法题】

a={1,2,2,2,3}（下标0~4），lower_bound(2)与upper_bound(2)的下标？2的个数？

查看解析

1 和 4；个数3。口诀：左闭右开，[lb, ub) 即等值区间。

【例2·408风格应用题】

递增数组中插入x使仍递增，求插入位置；并统计x的出现次数（x可能不存在）。

查看解析
int pos = lower_bound(a, a + n, x) - a;          // 插入位置
int cnt = upper_bound(a, a + n, x) - lower_bound(a, a + n, x);   // 出现次数

笔试对应折半查找"查找失败时的比较位置即插入位置"——判定树画法见第四部分5.1；二分变形题见第七部分 LC35/LC34。

15. unique（相邻去重）必考模板

🔗 王道考点联动：第8章 排序应用 —— 先排序后去重的经典组合。原理精讲见王道精讲页对应小节。

🎬 对应课程：L17 排序 + L5 数组技巧（先有序再相邻去重） ｜ 考试规则见 L0/L26

原型：ForwardIt unique(ForwardIt first, ForwardIt last);

语义（必背）：把相邻重复元素"挤"到后面：不重复元素依次前移，返回新逻辑尾后迭代器。物理长度不变，尾部是残留值。标准用法"先sort再unique再erase"。

vector<int> v = {5, 1, 3, 1, 5, 1};
sort(v.begin(), v.end());                    // 1 1 1 3 5 5
auto last = unique(v.begin(), v.end());      // 1 3 5 ? ? ?（逻辑尾）
v.erase(last, v.end());                      // 1 3 5
// 一行版：v.erase(unique(v.begin(), v.end()), v.end());  前提：已排序
高频易错点：①只处理相邻重复，不排序不能全局去重；②unique本身O(n)，整体瓶颈是sort的O(nlogn)；③erase区间删除左闭右开。
unique O(n)全局去重 O(nlogn)
【例1·基础判断题】

对 v={1,2,1,2} 执行 unique 后，v内容与返回值- begin 为？

查看解析

v仍为{1,2,1,2}，返回end（差为4）。没有相邻相等对，一个都不删——必须先排序。

【例2·408风格应用题】

n个整数可能重复，输出去重后的升序序列（机试），并说明与set方案的区别。

查看解析

见上方"三连"，O(nlogn)。set方案：set<int> s; 边插边去重，代码更短但常数大、无下标访问。完整对比如第六部分·实战 e1。

16. nth_element（部分排序/第k小）必考模板

🔗 王道考点联动：第8章 堆与快速选择 —— TopK问题：堆O(nlogk)思想。原理精讲见王道精讲页对应小节。

🎬 对应课程：L19 快速选择 QuickSelect（Partition 单边递归） ｜ 考试规则见 L0/L26

原型：void nth_element(RandomIt first, RandomIt nth, RandomIt last);

语义（必背）：执行后，nth位置就是完全排序后它该在的位置，且左边都≤它、右边都≥它（两边内部无序）。本质=快速选择，平均O(n)。

nth_element(v.begin(), v.begin() + 2, v.end());    // v[2]=第3小
int kth = v[k - 1];                                 // 先 nth_element(begin+k-1,...) 再取
nth_element(v.begin(), v.begin() + n / 2, v.end()); // 中位数（n奇数）
int mid = v[n / 2];
应试注意：只求第k小不必全排序——比sort便宜；笔试手写=快排Partition+单边递归（见第四部分6.3与第七部分LC215）。
平均 O(n)空间 O(1)
【例1·基础用法题】

求n个数的第k大（k≤n）。

查看解析
nth_element(v.begin(), v.begin() + n - k, v.end());  // 第k大=第n-k+1小
cout << v[n - k] << endl;
【例2·408真题风格应用题】

不用完整排序求n个无序整数的中位数，说明思想与复杂度。

查看解析

快速选择：枢轴划分后，p==中位位置即答案；偏大只递归左半、偏小只递归右半。n+n/2+n/4+…≈2n → 平均O(n)，最坏O(n²)；空间O(1)（迭代版）。机试一行：nth_element(v.begin(), v.begin()+n/2, v.end());

17. max / min / max_element / min_element

🔗 王道考点联动：第8章 简单选择排序 —— 一趟选最值=选择排序思想。原理精讲见王道精讲页对应小节。

🎬 对应课程：L2 SelectMaxMin/BinarySelect 的最简版 ｜ 考试规则见 L0/L26

原型：max(a, b); min(a, b); max({a, b, c});（C++11花括号版）
ForwardIt max_element(first, last);　ForwardIt min_element(first, last);

参数与返回值：max/min返回值；max_element/min_element返回迭代器（多个最值取第一个），O(n)线性扫描。下标：max_element(a, a+n) - a。

int a[] = {4, 9, 2, 9, 7};
int mx = *max_element(a, a + 5);        // 9（值，记得解引用）
int mi = max_element(a, a + 5) - a;     // 1（第一个最大值下标）
int m = max(3, 5);
int n = max({3, 5, 8, 1});              // 8
易错：max_element返回迭代器不是值，输出要 *it；笔试求最值下标建议手写一行for。
max/min O(1)*_element O(n)
【例1·基础判断题】

cout << max_element(a, a+5); 输出9吗？

查看解析

不是——输出的是地址（int*）。应写 *max_element(a, a+5) 取值。

【例2·408风格应用题】

顺序表求最大值与最小值，要求比较次数尽量少（进阶）。

查看解析

基础：两次扫描O(2n)。优化：成对比较（先比一对大小，大者与max比、小者与min比），比较次数降为 ⌈3n/2⌉−2——408"比较次数优化"经典结论。

18. swap（交换）

🔗 王道考点联动：第2章 顺序表操作 —— 逆置/交换的基础操作。原理精讲见王道精讲页对应小节。

🎬 对应课程：L3 链表插入删除的原子操作 ｜ 考试规则见 L0/L26

原型：void swap(T& a, T& b);

两级语义：①元素级 swap(v[i], v[j]) O(1)——排序/双指针高频；②容器级 swap(v1, v2) 只换内部指针，O(1)不搬元素，迭代器随容器互换。

swap(a[0], a[2]);         // 元素级 O(1)
swap(a, b);               // 容器级 O(1)，只交换内部指针/size/capacity
vector<int>().swap(v);    // 技巧：与空vector交换，真正释放内存
元素级 O(1)容器级 O(1)
【例1·基础选择题】

swap(v1, v2)（两个满vector）的时间复杂度与 v1 = v2 的区别？

查看解析

swap是O(1)（只换三个字段）；赋值是O(n)复制。迭代器swap后"跟着数据走"。

【例2·408风格应用题】

手写swap交换两个整型变量（不用临时变量的进阶写法）。

查看解析
void mySwap(int &a, int &b) { int t = a; a = b; b = t; }        // 标准写法（笔试首选）
void xorSwap(int &a, int &b) { a ^= b; b ^= a; a ^= b; }        // 异或版（仅当a、b不同址）

笔试写临时变量版——异或版a、b同一地址时会把自身清0，属于隐藏坑。

19. 工具类：pair（二元组）机试可用高频考点

🔗 王道考点联动：第7章 查找表存储 —— 二元组<关键字,卫星数据>。原理精讲见王道精讲页对应小节。

🎬 对应课程：L11 哈夫曼（结点权值+编号入堆）、L15 堆优化 Dijkstra ｜ 考试规则见 L0/L26

核心定义：捆绑两个值：pair<T1,T2>，成员 first/second。map的元素就是pair。支持字典序（先first后second）→ 可直接sort、可直接进set。

pair<int, int> p(1, 2);              // 直接构造
auto q = make_pair(3, 4);            // 工厂函数自动推导
pair<int, string> r = {5, "x"};      // C++11列表初始化

vector<pair<int, int>> v;
v.push_back({3, 7});
sort(v.begin(), v.end());            // 默认first升序，first相同second升序

// first升序、second降序：必须自写cmp
sort(v.begin(), v.end(),
     [](const pair<int,int> &a, const pair<int,int> &b) {
         if (a.first != b.first) return a.first < b.first;
         return a.second > b.second;
     });
构造/访问 O(1)比较 字典序
【例1·基础选择题】

vector<pair<int,int>> 直接sort（不传cmp）的排序规则？

查看解析

first升序；first相同按second升序（字典序）。要"第二维降序"必须自写cmp。

【例2·408风格应用题】

n个区间 [lᵢ, rᵢ]，按左端点升序排列（左端点相同按右端点降序），为"合并区间"做准备。

查看解析
sort(v.begin(), v.end(), [](const pair<int,int> &a, const pair<int,int> &b) {
    if (a.first != b.first) return a.first < b.first;
    return a.second > b.second;
});

这正是LC56合并区间的预处理步骤（第七部分），笔试常以"区间调度"变体出现。

20. 工具类：tuple（多元组）了解即可

🔗 王道考点联动：第6章 图的边结构 —— 多元组存"(边权,端点)"是Dijkstra/Kruskal标配。原理精讲见王道精讲页对应小节。

核心介绍：pair 的n元推广。408机试中三元以上才用得上（如"(边权,端点1,端点2)"），一般 pair 嵌套或小结构体更清晰。掌握三件事：构造、get取值、tie解包。

tuple<int, string, double> t = make_tuple(1, "w", 3.5);
int id = get<0>(t);                  // 按编译期下标取值
string name = get<1>(t);

int a; string b; double c;
tie(a, b, c) = t;                    // 解包到已有变量；用ignore占位：tie(a, ignore, c)
auto [x, y, z] = t;                  // 结构化绑定是C++17语法，408按C++11作答请用tie！
注意：结构化绑定 auto [x,y,z] 是 C++17 语法。408按C++11标准作答，代码示例一律用 tie 或 get<i>，避免阅卷环境不兼容。
get<i> O(1)tie解包 O(1)
【例题·408风格·选择题】

下列哪种写法不符合C++11标准？A. make_tuple(1,2)　B. get<0>(t)　C. auto [a,b] = t;　D. tie(a,b) = t;

查看答案

C。结构化绑定是C++17引入。408机试/复试环境若只支持C++11，该写法无法编译——这也是本手册所有代码遵守C++11的原因。

21. 工具类：自定义比较函数 / 仿函数（cmp重载写法必考）必考模板高频考点

🔗 王道考点联动：第8章 排序稳定性与比较 —— 自定义比较=排序题的核心考点。原理精讲见王道精讲页对应小节。

🎬 对应课程：L18 优先队列比较方向（greater→小根堆）、L11 建树排序 ｜ 考试规则见 L0/L26

核心定义：凡是带比较器的场合（sort/stable_sort/set/map/priority_queue），比较器都要求严格弱序：①cmp(a,a)==false；②对称反对称；③可传递。相等必须返回false是铁律。

四种比较器写法 + 三大容器比较器方向对照

// ① 普通函数（sort用）
bool cmp(const Stu &a, const Stu &b) { return a.score > b.score; }
sort(v.begin(), v.end(), cmp);

// ② 仿函数（函数对象）：重载 operator()
struct CmpScore {
    bool operator()(const Stu &a, const Stu &b) const { return a.score > b.score; }
};
sort(v.begin(), v.end(), CmpScore());

// ③ lambda（C++11，机试推荐）
sort(v.begin(), v.end(), [](const Stu &a, const Stu &b) { return a.score > b.score; });

// ④ 预置仿函数：greater<T>() 降序、less<T>() 升序
sort(v.begin(), v.end(), greater<int>());

// ===== 容器比较器方向对照（最易混，必背） =====
// sort:     cmp(a,b)==true  → a排在b前面
// set/map:  cmp(a,b)==true  → a排在b前面（同sort，默认less升序）
// priority_queue: cmp(a,b)==true → a优先级"低"、排在后面！
//   默认less → 大根堆；greater → 小根堆（方向与sort相反）
高频易错点：①priority_queue的比较器方向与sort相反（greater得出小根堆）——写完必须验证一次堆顶；②set/map自定义类型比较器要加 const（两个形参与函数本身）；③相等返回true（≥/≤）会让sort崩溃。
比较器本身 O(1)方向陷阱 priority_queue 与 sort 相反
【例1·基础用法题】

定义结构体Point{x,y}，按x升序、x相同按y降序，分别用函数、仿函数、lambda三种方式写比较器。

查看解析
struct Point { int x, y; };
bool cmpF(const Point &a, const Point &b) {
    return a.x != b.x ? a.x < b.x : a.y > b.y;
}
struct CmpO { bool operator()(const Point &a, const Point &b) const {
    return a.x != b.x ? a.x < b.x : a.y > b.y; } };
auto cmpL = [](const Point &a, const Point &b) { return a.x != b.x ? a.x < b.x : a.y > b.y; };
sort(p.begin(), p.end(), cmpF);   // 或 CmpO() / cmpL
【例2·408风格辨析题】

想要"最小元素优先"的优先队列，下面两种写法哪个对？为什么？
A. priority_queue<int, vector<int>, greater<int>>　B. priority_queue<int, vector<int>, less<int>>

查看解析

A对。priority_queue中"比较返回true=优先级低、靠后"，greater(int)表示"大的靠后"，堆顶即最小。B是默认行为=大根堆。这就是"比较器方向与sort相反"的典型体现。
