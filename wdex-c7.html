7.2 · 综合第1题综合

若对有n个元素的有序顺序表和无序顺序表进行顺序查找，试就下列三种情况分别讨论两者在相等查找概率时的平均查找长度是否相同。
(1) 查找失败。
(2) 查找成功，且表中只有一个关键字等于给定值k的元素。
(3) 查找成功，且表中有若干关键字等于给定值k的元素，要求一次查找能找出所有元素。

查看解答

【解答】

解答：(1) 不相同。无序表必须从头扫到尾才能断定失败，需比较n+1次（含越界判断）；有序表一旦当前元素≥k即可提前终止，失败位置等概率落在n+1个间隙，各需比较1,2,…,n+1次，平均(n+2)/2次，故有序表更优。

(2) 相同。两种表查找成功且元素唯一时，都须从头逐个比较到该元素为止，平均比较次数均为(1+2+…+n)/n=(n+1)/2。

(3) 不相同。有序表中相等元素连续存放，从头找到第一个等于k的元素后继续向后扫描直到大于k即得全部结果，比较次数=定位首元素的比较次数+同值元素个数，平均约为(n+1)/2+m（m为等值元素个数期望）；无序表中相等元素分散，必须扫描全部n个元素才能找齐。故有序表平均比较次数更少，两者不相同。

D. 无法确定
查看解析与答案

7.2 · 综合第3题综合

已知一个有序顺序表A[0…8n-1]的表长为8n，并且表中没有关键字相同的数据元素。假设按下述方法查找一个关键字值等于给定值X的数据元素：首先在A[7]，A[15]，A[23]，…，A[8k-1]，…，A[8n-1]中进行顺序查找，若查找成功，则算法报告成功位置并返回；若不成功，当A[8k-1]<X<A[8×(k+1)-1]时，可确定一个缩小的查找范围A[8k]～A[8×(k+1)-2]，然后可在这个范围内执行折半查找。特殊情况：若X>A[8n-1]的关键字，则查找失败。

查看解答

【解答】

解答：(1) 判定树的结构：最左是一条"脊柱"链，结点依次为A[7]，A[15]，…，A[8n-1]（每个结点的右孩子是链上的下一个结点）；每个结点A[8k-1]的左子树是块内7个元素A[8k-8]～A[8k-2]的折半判定树，是一棵3层满二叉树：根为第4个元素A[8k-5]，第二层为A[8k-7]、A[8k-3]，叶层为A[8k-8]、A[8k-6]、A[8k-4]、A[8k-2]：

A[7] --- A[15] --- A[23] --- ... --- A[8n-1] (脊柱：右孩子为链上下一结点)
| | | |
7元满树 7元满树 7元满树 ... 7元满树 (每棵左子树高3)

(2) 块尾元素A[8k-1]查到需k次比较；块内7个元素各需k次（定块）+块内折半平均3次。故ASL=[Σ(k) + Σ7(k+3)]/(8n)=[Σ8k+21n]/(8n)=[8·n(n+1)/2+21n]/(8n)=(4n+25)/8。

7.2 · 综合第4题综合

写出折半查找的递归算法。初始调用时，low为1，high为ST.length。

查看解答

【解答】

解答：思路：在[low,high]内取mid=⌊(low+high)/2⌋，与key比较；相等返回；key更小则递归左半区间，更大则递归右半区间；low>high时失败。代码：

int BinSearch(SSTable ST, int low, int high, KeyType key){
if (low > high) return 0; // 查找失败
int mid = low + (high - low) / 2; // 防溢出写法
if (key == ST.elem[mid].key) return mid;
else if (key < ST.elem[mid].key)
return BinSearch(ST, low, mid-1, key);
else
return BinSearch(ST, mid+1, high, key);
}

每次递归区间减半，时间复杂度O(log₂n)，递归深度即判定树高度。也可改为尾递归消除的循环版，避免递归栈开销。

7.2 · 综合第5题综合

线性表中各结点的检索概率不等时，可用如下策略提高顺序检索的效率：若找到指定的结点，则将该结点和其前驱结点（若存在）交换，使得经常被检索的结点尽量位于表的前端。试设计在顺序结构和链式结构的线性表上实现上述策略的顺序检索算法。

查看解答

【解答】

解答：思路：顺序检索到目标后，若它不是首元素，则与其直接前驱交换位置；高频结点会逐渐"冒泡"到表前端。

顺序表版：

int SeqSearch(ElemType a[], int n, KeyType key){
for (int i = 0; i < n; i++)
if (a[i].key == key){
if (i > 0) { ElemType t=a[i]; a[i]=a[i-1]; a[i-1]=t; }
return i-1; // 交换后新位置
}
return -1;
}

链表版：查找时带一个前驱指针pre，命中后把结点从链中摘下，插到其前驱之前（首元结点位置）。两种结构单次查找均为O(n)，但期望比较次数随访问频度前移而下降；链表版还可设置头结点统一处理首结点交换。

7.2 · 综合第6题综合

已知一个n阶矩阵A和一个目标值k。该矩阵无重复元素，每行从左到右升序排列，每列从上到下升序排列。请设计一个在时间上尽可能高效的算法，判断矩阵中是否存在目标值k（例如矩阵[[1,4,7],[2,5,8],[3,6,9]]，目标值为8，判断存在）。要求：
(1) 给出算法的基本设计思想。
(2) 根据设计思想，采用C或C++语言描述算法，关键之处给出注释。
(3) 说明你的算法的时间复杂度和空间复杂度。

查看解答

【解答】

解答：(1) 从矩阵右上角出发比较：当前元素大于k则本列其余元素都更大，删去该列（左移）；当前元素小于k则本行其余元素都更小，删去该行（下移）；等于则找到。每步排除一行或一列，最多n+n=2n步。

(2) 代码：

bool searchMatrix(int A[][N], int n, int k){
int i = 0, j = n - 1; // 从右上角出发
while (i < n && j >= 0) {
if (A[i][j] == k) return true;
else if (A[i][j] > k) j--; // 排除当前列
else i++; // 排除当前行
}
return false;
}

(3) 时间复杂度O(n)（每轮行列指标各最多移动n次），空间复杂度O(1)。也可从左下角出发，同理。

7.2 · 综合第7题综合

设顺序表S中有4个元素，它们的查找概率依次为P1=0.35，P2=0.15，P3=0.15，P4=0.35。将S保存在一个长度为4的顺序表中，采用折半查找法，查找成功时的平均查找长度为2.2。
(1) 若采用顺序存储结构保存S，且要求平均查找长度更短，则元素应如何排列？应使用何种查找方法？查找成功时的平均查找长度是多少？
(2) 若采用链式存储结构保存S，且要求平均查找长度更短，则元素应如何排列？应使用何种查找方法？查找成功时的平均查找长度是多少？

查看解答

【解答】

解答：先验证折半：按P1、P2、P3、P4的顺序存放时，判定树第2个元素在1层、第1、3个在2层、第4个在3层，ASL=0.15×1+(0.35+0.15)×2+0.35×3=2.2，与题设一致。

(1) 顺序存储：按查找概率从大到小排列（P1、P4、P2、P3对应元素），改用顺序查找：ASL=0.35×1+0.35×2+0.15×3+0.15×4=0.35+0.7+0.45+0.6=2.1<2.2。

BiTNode *prev = NULL;
bool isBST(BiTNode *p){ // 中序递归
if (p == NULL) return true;
if (!isBST(p->lchild)) return false;
if (prev && p->data.key <= prev->data.key) return false;
prev = p; // 更新前驱

level++;
}

}

查看解答

【解答】

解答：思路：后序遍历自底向上返回子树高度；任一结点左右子树高度差超过1则全局不平衡。用-1表示"子树已失衡"短路返回。

int postHeight(BiTNode *p){
if (p == NULL) return 0;
int lh = postHeight(p->lchild);
if (lh == -1) return -1;
int rh = postHeight(p->rchild);
if (rh == -1) return -1;
if (lh - rh > 1 || rh - lh > 1) return -1; // 失衡
return (lh > rh ? lh : rh) + 1; // 子树高度
}
bool isBalanced(BiTNode *t){ return postHeight(t) != -1; }

每个结点只访问一次，时间O(n)，空间O(h)。若题目只要求"每个结点左右子树高度差≤1"而不要求BST有序性，该算法即为判断平衡二叉树的标准解。

7.4 · 综合第10题综合

编写一个递归算法，在一棵有n个结点的、随机建立起来的二叉排序树上查找第k（1≤k≤n）小的元素，并返回指向该结点的指针。要求算法的平均时间复杂度为O(log₂n)。二叉排序树的每个结点中除data、lchild、rchild等数据成员外，增加一个count成员，保存以该结点为根的子树上的结点个数。

查看解答

【解答】

解答：思路：中序序列中，若结点t的左子树有L个结点，则t是第L+1小。比较k与L+1决定向左、命中或向右（向右时k减去L+1）。每个结点存count=子树结点数，则L=lchild?lchild->count:0。

BSTNode *kth(BSTNode *t, int k){
if (t == NULL || k < 1 || k > t->count) return NULL;
int L = (t->lchild) ? t->lchild->count : 0; // 左子树结点数
if (k == L + 1) return t; // t即第k小
else if (k <= L) return kth(t->lchild, k); // 在左子树中找第k小
else return kth(t->rchild, k-L-1); // 右子树中找第k-L-1小
}

每次递归下降一层，随机建立的BST平均高度O(log₂n)，故平均时间复杂度O(log₂n)，空间为递归栈O(log₂n)。注意插入/删除时须同步维护count。
