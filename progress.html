打卡进度

📅 打卡与学习进度

每日打卡记录学习习惯，各模块「已学」汇总为进度条。数据保存在浏览器 localStorage，配置 Supabase 后多设备云端同步。

📅 每日打卡

🎤 同学们，坚持每天打开网站学一点：学完随便哪个模块，回这里点一下打卡；各内容页小节右侧的「◻ 已学」按钮点了也会计入进度。

🔥 连续 0 天📅 累计 0 天

📚 模块学习进度

🎤 进度 = 各页里你点过「已学」的小节/题目数 ÷ 该页总数。点模块名直达对应页面继续学习。

⚠ 数据说明未配置 Supabase 时数据仅存于本浏览器（清理浏览器数据会丢失）；云端模式下打卡与进度通过 Supabase 表 ds_state 按设备ID同步。
