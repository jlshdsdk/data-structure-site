一个完整的数据结构通常应包含以下哪些要素（）

A. 数据元素及其存储方式
B. 数据的逻辑结构和物理结构
C. 数据的逻辑结构、存储结构以及在其上定义的基本操作

查看解析与答案

【解析】

独立验算：选C。数据结构的研究内容包括三个要素：数据的逻辑结构（元素之间的逻辑关系）、数据的存储结构（逻辑结构在计算机中的映像）以及定义在其上的基本运算。C 完整覆盖三要素。A 只涉及数据元素及其存放，遗漏了运算；B 只是三要素中的两个；D 仅是逻辑结构层面的描述，均不完整。

✅ 答案：C　📖 王道书解析 P4

1.1 · 综合第1题综合

对于两种不同的数据结构，逻辑结构或物理结构一定不相同吗？

查看解答

【解答】

思路：数据结构包含逻辑结构、存储结构（物理结构）和数据的运算三个要素。两种数据结构不同，可能是其中任一要素不同，因此逻辑结构和物理结构不一定都不同。

论证（举反例）：①逻辑结构相同、存储结构不同：顺序栈与链栈的逻辑结构都是栈（操作受限的线性表），但前者采用顺序存储、后者采用链式存储，是两种不同的数据结构；②存储结构形式相同、逻辑结构不同：顺序表与顺序栈都可利用一维数组的相邻位置存放元素，但二者的运算定义不同——线性表允许在任意位置插入和删除，栈只允许在栈端操作，它们也是两种不同的数据结构。

结论：不一定。两种不同的数据结构，可能仅逻辑结构不同，也可能仅存储结构不同，甚至逻辑结构和存储结构都相同而基本运算的定义不同。判断两种数据结构是否相同，必须同时考察逻辑结构、存储结构和运算三个方面。

1.1 · 综合第2题综合

举例说明对相同的逻辑结构，同一种运算在不同的存储方式下实现时，其运算效率不同。

查看解答

【解答】

思路：逻辑结构决定“能做什么运算”，存储结构决定“运算如何实现”。以线性表（逻辑结构）为例，对比顺序存储与链式存储下同一运算的效率。

例1（插入运算）：在顺序存储的线性表第 i 个位置插入元素，需将第 i 个及之后的所有元素依次后移，平均移动约 n/2 个元素，时间复杂度为 O(n)；在链式存储中，定位到插入位置后只需修改两个指针即可完成，插入本身仅为 O(1)（若计入从头定位则为 O(n)，但无需成块搬移数据）。

例2（按序号查找）：顺序表支持随机存取，按序号 i 直接计算地址，时间复杂度 O(1)；单链表必须从表头结点顺链逐个扫描，时间复杂度 O(n)。

结论：相同的逻辑结构（线性表）上的同一种运算，在不同存储结构下实现效率可以相差一个数量级，说明运算的实现方法与效率依赖于所选择的存储结构，实际设计中应根据各运算的使用频率权衡选择。

1.2 · 综合第1题综合

分析下列各程序段，求出算法的时间复杂度。

(1) i=1; k=0;
    while(i<=n-1){
        k=k+10*i;
        i++;
    }
(2) y=0;
    while((y+1)*(y+1)<=n)
        y=y+1;
(3) for(i=0; i<n; i++)
    for(j=0; j<m; j++)
        a[i][j]=0;
查看解答

【解答】

思路：找出各程序段中执行次数最多的基本语句，统计其频度关于问题规模的增长阶。

（1）i 从 1 开始每轮增 1，循环条件 i≤n−1，循环体（k=k+10*i; i++）共执行 n−1 次，每次为常数时间，故 T₁(n)=n−1=O(n)。双法验算：i 的取值为 1…n−1 共 n−1 个，频度与 n 成正比。

（2）循环条件为 (y+1)²≤n，等价于 y+1≤⌊√n⌋。y 从 0 起每轮增 1，当 y=k 时需 (k+1)²≤n 即 k+1≤√n，故循环执行约 ⌊√n⌋ 次，T₂(n)=O(√n)。

（3）两重循环相互独立：外层 i 执行 n 次，内层对每个 i 执行 m 次，赋值语句 a[i][j]=0 共执行 n·m 次，T₃(n)=O(n·m)。注意 m 与 n 是两个独立的问题规模参数，不能写成 O(n²)。

结论：三段程序的时间复杂度依次为 O(n)、O(√n)、O(n·m)。

1.2 · 第2题选择

下列关于算法的说法中，正确的是（）

A. 算法的时间效率取决于算法执行所花的CPU时间
B. 在算法设计中不允许用牺牲空间效率的方式来换取好的时间效率
C. 算法必须具备有穷性、确定性等五个特性
D. 通常用时间效率和空间效率来衡量算法的优劣
查看解析与答案

【解析】

独立验算：选C。算法必须具备有穷性、确定性、可行性、输入、输出这五个特性，C 正确。A 错：算法的时间效率应以基本运算的频度衡量，与具体机器无关，实际 CPU 时间受硬件和负载影响；B 错：算法设计中允许以空间换时间；D 错：时空效率只衡量算法的“效率”，衡量算法优劣还应考虑正确性、可读性、健壮性等。

1.2 · 第3题选择

某算法的时间复杂度为O(n²)，表明该算法的（）

A. 问题规模是n²
B. 执行时间等于n²
C. 执行时间与n²成正比
D. 问题规模与n²成正比
查看解析与答案

【解析】

独立验算：选C。O(n²) 刻画的是算法执行时间 T(n) 随问题规模增长的渐近数量级：存在常数 c，使 T(n)≤c·n²，即执行时间与 n² 同阶（成正比）。A、D 错：该算法的问题规模是 n 而非 n²；B 错：时间复杂度只描述增长趋势，并非执行时间精确等于 n²。

1.2 · 第4题选择

若某算法的空间复杂度为O(1)，则表示该算法（）

A. 不需要任何辅助空间

C. 不需要任何空间
D. 所需空间大小与问题规模n无关
查看解析与答案

【解析】

独立验算：选B。空间复杂度 S(n)=O(1) 指算法运行所需的辅助空间为常数个存储单元，其大小不随问题规模 n 变化。A 过强：O(1) 允许使用少量常数个辅助变量，并非“不需要任何辅助空间”；C 更是不可能的；D 错：算法所需总空间还包含程序代码与输入数据本身（随 n 增长），O(1) 只约束辅助空间。

1.2 · 第5题选择

下列关于时间复杂度的函数中，时间复杂度最小的是（）

A. T₁(n)=nlog₂n+5000n
B. T₂(n)=n²−8000n
C. T₃(n)=nlog₂n−6000n
D. T₄(n)=20000log₂n
查看解析与答案

1.2 · 第6题选择

以下算法的时间复杂度为（）

void fun(int n){
  int i=1;
  while(i<=n)
    i=i*2;
}
A. O(n)
B. O(n²)
C. O(nlog₂n)
D. O(log₂n)
查看解析与答案

【解析】

独立验算：选D。变量 i 依次取 1, 2, 4, …, 2^k，每轮循环翻倍。设第 k+1 次判断时退出，则 2^k≤n<2^(k+1)，即 k=⌊log₂n⌋，基本运算 i=i*2 共执行 ⌊log₂n⌋+1 次，为对数阶 O(log₂n)。若误认为 i 每轮只加固定量会错选 O(n)。

✅ 答案：D　📖 王道书解析 P9

1.2 · 第7题选择

下列算法的时间复杂度为（）

void fun(int n){
  int i=1;
  while(i*i*i<=n)
    i++;
}
A. O(n)
B. O(nlog₂n)
C. O(∛n)
D. O(√n)
查看解析与答案

【解析】

独立验算：选C。循环继续的条件是 i·i·i≤n，即 i≤∛n（n 的立方根）。i 从 1 开始每轮增 1，最多增至 ⌊∛n⌋，基本运算执行约 n^(1/3) 次，故为 O(∛n)。注意干扰项 D：√n=n^(1/2) 与 ∛n=n^(1/3) 是不同的阶，前者增长更快，二者不可混淆。

✅ 答案：C　📖 王道书解析 P9

1.2 · 第8题选择

某个程序段如下：

for(i=n-1; i>1; i--)
  for(j=1; j<i; j++)
    if(A[j]>A[j+1])
      A[j]与A[j+1]对换;

其中 n 为正整数，则最后一行语句的频度在最坏情况下是（）

A. O(n)
B. O(nlog₂n)
C. O(n³)
D. O(n²)
查看解析与答案

【解析】

独立验算：选D。最坏情况（逆序）下每次比较都会触发对换。外层 i 从 n−1 递减到 2，对每个 i，内层 j 共执行 i−1 次，故对换语句的总频度 = Σ(i−1)（i 从 2 到 n−1）= 1+2+…+(n−2) = (n−1)(n−2)/2 = ½n²−(3/2)n+1，为 n² 阶，故选D。

✅ 答案：D　📖 王道书解析 P9

1.2 · 第9题选择

下列程序段的时间复杂度为（）

if(n>=0){
  for(int i=0; i<n; i++)
    for(int j=0; j<n; j++)
      printf("输入数据大于或等于零");
}
else{
  for(int j=0; j<n; j++)
    printf("输入数据小于零");
}
A. O(n²)
B. O(n)
C. O(1)
D. O(nlog₂n)
查看解析与答案

【解析】

独立验算：选A。if-else 两个分支的执行时间应取最坏者：n≥0 分支是双重嵌套循环，printf 执行 n·n=n² 次；else 分支只有单重循环，执行 n 次。时间复杂度按最坏情况计为 O(n²)，故选A。若只看 else 分支会错选 O(n)。

✅ 答案：A　📖 王道书解析 P9

1.2 · 第10题选择

下列算法中加下划线的语句的执行次数为（）

int m=0, i, j;
for(i=1; i<=n; i++)
  for(j=1; j<=2*i; j++)
    m++;  // 加下划线的语句
A. n(n+1)
B. n
C. n+1

1.2 · 第11题选择

下列函数代码的时间复杂度是（）

int Func(int n){
  if(n==1) return 1;
  else return 2*Func(n/2)+n;
}
A. O(n)
B. O(nlog₂n)
C. O(log₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选C。关键在于 return 语句中只调用了一次 Func(n/2)，系数 2 只是返回值的乘法运算，并不会使调用次数翻倍。设 T(n)=T(n/2)+O(1)，实参经 ⌊log₂n⌋ 次减半降为 1，递归共 log₂n+1 层，每层仅常数次基本运算，故 T(n)=O(log₂n)。若误当作分治方程 T(n)=2T(n/2)+n 会错选B。

✅ 答案：C　📖 王道书解析 P9

1.2 · 第12题选择

【2011统考真题】设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（）

x=2;
while(x<n/2)
  x=2*x;
A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选A。x 依次取 2¹, 2², …, 2^k，每轮循环翻倍。设执行 k 次后退出，则 2^k<n/2，即 k<log₂(n/2)=log₂n−1，循环体执行次数约为 log₂n−2，为对数阶，故选A。注意循环条件是 n/2，只影响常数项，不改变阶。

✅ 答案：A　📖 王道书解析 P10

1.2 · 第13题选择

【2012统考真题】求整数 n（n≥0）的阶乘的算法如下，其时间复杂度是（）

int fact(int n){
  if(n<=1) return 1;
  return n*fact(n-1);
}
A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选B。递归调用链为 n→n−1→…→1，共发生 n 次函数调用，每次调用内除递归外只有常数次乘法与比较，故 T(n)=T(n−1)+O(1)=O(n)。这是单支递归且规模每次减 1（而非减半），不要与二分类递归的 O(log₂n) 混淆。

✅ 答案：B　📖 王道书解析 P10

1.2 · 第14题选择

【2014统考真题】下列程序段的时间复杂度是（）

count=0;
for(k=1; k<=n; k*=2)
  for(j=1; j<=n; j++)
    count++;
A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选C。外层 k 按 1, 2, 4, … 几何级数增长，共执行 ⌊log₂n⌋+1 次；每轮外层循环中内层固定执行 n 次 count++，总执行次数约为 n·log₂n，故时间复杂度为 O(nlog₂n)。只看外层会错选A，误以为内层也是倍增会错算出更高阶。

✅ 答案：C　📖 王道书解析 P10

1.2 · 第15题选择

【2017统考真题】下列函数的时间复杂度是（）

int func(int n){
  int i=0, sum=0;
  while(sum<n)
    sum += ++i;
  return i;
}
A. O(log₂n)
B. O(√n)
C. O(n)
D. O(nlog₂n)
查看解析与答案

【解析】

独立验算：选B。第 k 轮循环结束时 sum=1+2+…+k=k(k+1)/2。循环在 sum≥n 时停止，即 k(k+1)/2≥n，解得 k 约为 √(2n)，循环（及 ++i）执行次数与 √n 同阶，故为 O(√n)。sum 的增量本身在增大，不是常数，故不能选 O(n)。

✅ 答案：B　📖 王道书解析 P10

【2019统考真题】设 n 是描述问题规模的非负整数，下列程序段的时间复杂度是（）

x=0;
while(n>=(x+1)*(x+1))
  x=x+1;
A. O(log₂n)
B. O(√n)
C. O(n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选B。循环继续的条件是 (x+1)²≤n，即 x+1≤⌊√n⌋。x 从 0 开始每轮增 1，至多执行 ⌈√n⌉−1 次循环，基本运算次数与 √n 同阶，故为 O(√n)。x 是线性增长、由平方条件约束，与翻倍无关，不存在对数阶。

✅ 答案：B　📖 王道书解析 P10

【2022统考真题】下列程序段的时间复杂度是（）

int sum=0;
for(int i=1; i<n; i*=2)
  for(int j=0; j<i; j++)
    sum++;
A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选B。外层 i 取 1, 2, 4, …, 2^⌊log₂(n−1)⌋，内层对每个 i 执行 i 次，sum++ 的总次数 = 1+2+4+…+2^⌊log₂(n−1)⌋ < 2·2^⌊log₂(n−1)⌋ ≤ 2n。等比级数求和收敛于 n 的常数倍，故为 O(n)。内层上界不是固定的 n，直接相乘得 O(nlog₂n) 是典型错误。

✅ 答案：B　📖 王道书解析 P10

1.2 · 第18题选择

【2025统考真题】下列程序段的时间复杂度是（）

int count=0, i, j;
for(i=1; i*i<=n; i++)
  for(j=1; j<=i; j++)
    count++;
A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)
查看解析与答案

【解析】

独立验算：选B。外层条件 i²≤n 限制 i 至多取到 ⌊√n⌋；内层对每个 i 执行 i 次，count++ 总次数 = Σi（i 从 1 到 ⌊√n⌋）= ⌊√n⌋(⌊√n⌋+1)/2 ≈ n/2，与 n 同阶，故为 O(n)。两层循环相乘得 O(n·√n) 或 O(n²) 都未利用上界关系，是错误的估算。

✅ 答案：B　📖 王道书解析 P11
