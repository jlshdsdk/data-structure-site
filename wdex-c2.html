2.2 · 综合第1题综合

从顺序表中删除具有最小值的元素（假设唯一）并由函数返回被删元素的值。空出的位置由最后一个元素填补，若顺序表为空，则显示出错信息并退出运行。

查看解答

【解答】

思路：顺序扫描一遍求出最小值元素的下标 idx，用返回参数带回其值；按题意用表尾元素填到 idx 处，再把表长减 1，避免成片移动元素。

bool Del_Min(SqList &L, ElemType &value) {
if (L.length == 0) return false; // 空表：报错退出
int idx = 0; // 最小值元素下标
for (int i = 1; i < L.length; i++)
if (L.data[i] < L.data[idx]) idx = i;
value = L.data[idx]; // 返回被删元素值
L.data[idx] = L.data[L.length - 1]; // 尾元素填补空位
L.length--; // 表长减1
return true;
}

复杂度：一趟扫描定位最小值，时间 O(n)；只用常数个辅助变量，空间 O(1)。若不用尾元素填补而改为前移，删除后还要 O(n) 移动，效率更低。

2.2 · 综合第2题综合

设计一个高效算法，将顺序表 L 的所有元素逆置，要求算法的空间复杂度为 O(1)。

查看解答

【解答】

思路：就地逆置：设置双指针 i、j 分别指向表首和表尾，两者相向而行，每前进一步交换一对元素，相遇即止，不需要辅助数组。

void Reverse(SqList &L) {
ElemType t;
for (int i = 0, j = L.length - 1; i < j; i++, j--) {
t = L.data[i]; L.data[i] = L.data[j]; L.data[j] = t;
}
}

复杂度：共交换 ⌊n/2⌋ 对元素，时间 O(n)；仅用 1 个临时变量，空间 O(1)，满足要求。验算：(a₁,a₂,a₃,a₄) 逆置：交换 (1,4)、(2,3) 两对后得 (a₄,a₃,a₂,a₁)，正确。

B. 查找值为 x 的元素的时间与顺序表中元素个数 n 有关
C. 查找序号为 i 的元素的时间与顺序表中元素个数 n 无关

2.2 · 综合第3题综合

对长度为 n 的顺序表 L 编写一个时间复杂度为 O(n)、空间复杂度为 O(1) 的算法，该算法删除线性表中所有值为 x 的数据元素。

查看解答

【解答】

思路（用 k 记录已碰到的 x 的个数）：从头到尾扫描，凡遇到不等于 x 的元素就前移 k 位（k 是目前为止等于 x 的元素个数），遇到 x 只累计 k。这样每个保留元素只搬动一次，最后表长减 k。

void del_x(SqList &L, ElemType x) {
int k = 0; // 已删除（等于x）的元素个数
for (int i = 0; i < L.length; i++)
if (L.data[i] != x) L.data[i - k] = L.data[i];
else k++;
L.length -= k;
}

复杂度：一趟扫描，时间 O(n)、空间 O(1)。验算：L=(1,2,3,2,4)，x=2：i=0,1 正常；i=2 时 k=0 原位；i=3 累计 k=1；i=4 时前移到下标 3，得 (1,3,4)，表长 5-2=3，正确。亦可用“保留位置指针 j + 扫描指针 i”等价实现。

2.2 · 综合第4题综合

从顺序表中删除其值在给定值 s 与 t 之间（包含 s 和 t，要求 s<t）的所有元素，若 s 或 t 不合理或顺序表为空，则显示出错信息并退出运行。

查看解答

【解答】

思路：第 3 题的一般化：先做合法性检查（空表、s≥t 均不合法）；再用 k 统计当前已删除的 [s,t] 区间内元素个数，保留元素统一前移 k 位，最后表长减 k，一趟完成。

bool Del_s_t(SqList &L, ElemType s, ElemType t) {
if (s >= t || L.length == 0) return false; // 不合理或空表
int k = 0;
for (int i = 0; i < L.length; i++)
if (L.data[i] >= s && L.data[i] <= t) k++; // 落入[s,t]：删除计数
else L.data[i - k] = L.data[i]; // 否则前移k位
L.length -= k;
return true;
}

复杂度：时间 O(n)、空间 O(1)。验算：L=(1,2,3,4,5,6)，s=2，t=4：2、3、4 被删，k 累计到 3，5、6 分别前移至下标 1、2，得 (1,5,6)，正确。

2.2 · 综合第5题综合

从有序顺序表中删除所有其值重复的元素，使表中所有元素的值均不同。

查看解答

【解答】

思路：利用“有序”条件：重复元素必然相邻。用 i 指向已保留的最后一个不同元素，j 向后扫描，遇到 L.data[j] != L.data[i] 时就把它存到 ++i 处，类似建表的去重插入。

bool Del_Same(SqList &L) {
if (L.length == 0) return false;
int i = 0; // 已保留部分的最后一个下标
for (int j = 1; j < L.length; j++)
if (L.data[j] != L.data[i]) // 新的不同值
L.data[++i] = L.data[j];
L.length = i + 1;
return true;
}

复杂度：时间 O(n)、空间 O(1)。验算：(1,2,2,2,3,3,4)：j 扫描中 1 保留；两个 2 跳过；3 写入下标 2；第二个 3 跳过；4 写入下标 3，最终 (1,2,3,4)，正确。注意本题若表无序则不能这样做，需先排序或改用哈希判重。

2.2 · 综合第6题综合

将两个有序顺序表合并为一个新的有序顺序表，并由函数返回结果顺序表。

查看解答

【解答】

思路：归并：i、j、k 分别指向 A、B、C 的当前位置，每次把二者中较小者（相等时先取 A，保证稳定）放入 C，一方取尽后把另一方剩余元素批量接上。

bool Merge(SqList A, SqList B, SqList &C) {
if (A.length + B.length > C.MaxSize) return false; // 空间不足
int i = 0, j = 0, k = 0;
while (i < A.length && j < B.length)
C.data[k++] = (A.data[i] <= B.data[j]) ? A.data[i++] : B.data[j++];
while (i < A.length) C.data[k++] = A.data[i++]; // A有剩余
while (j < B.length) C.data[k++] = B.data[j++]; // B有剩余
C.length = k;
return true;
}

复杂度：每个元素恰好放入 C 一次，时间 O(n+m)；除结果表外只用常数变量。验算：(1,3,5) 与 (2,4,6) 归并得 (1,2,3,4,5,6)，正确。这是后面归并排序的基础操作。

2.2 · 综合第7题综合

已知在一维数组 A[m+n] 中依次存放两个线性表 (a₁,a₂,a₃,…,aₘ) 和 (b₁,b₂,b₃,…,bₙ)。编写一个函数，将数组中两个线性表的位置互换，即将 (a₁,…,aₘ,b₁,…,bₙ) 变换为 (b₁,…,bₙ,a₁,…,aₘ)。

【题干缺失部分按王道原题补全】

查看解答

【解答】

思路（三次逆置法）：先整体逆置，再分别逆置前 n 个和后 m 个元素：逆置后 a、b 两段各自内部次序恢复，而两段的位置恰好互换。每个元素至多被移动两次，无需辅助数组。

void Reverse(ElemType A[], int lo, int hi) { // 逆置A[lo..hi]
ElemType t;
for (; lo < hi; lo++, hi--) { t = A[lo]; A[lo] = A[hi]; A[hi] = t; }
}
void Exchange(ElemType A[], int m, int n) {
Reverse(A, 0, m + n - 1); // (b_n..b_1, a_m..a_1)
Reverse(A, 0, n - 1); // (b_1..b_n, a_m..a_1)
Reverse(A, n, m + n - 1); // (b_1..b_n, a_1..a_m)
}

复杂度：时间 O(m+n)，空间 O(1)。验算：m=3、n=2，(a₁,a₂,a₃,b₁,b₂)：整体逆置→(b₂,b₁,a₃,a₂,a₁)；逆前 2→(b₁,b₂,a₃,a₂,a₁)；逆后 3→(b₁,b₂,a₁,a₂,a₃)，正确。

2.2 · 综合第8题综合

线性表 (a₁,a₂,a₃,…,aₙ) 中的元素递增有序且按顺序存储于计算机内。要求设计一个算法，将元素 x 插入表中并使表中元素仍递增有序。

【题干缺失部分按王道原题补全】

查看解答

【解答】

思路：从表尾向前边比较边后移：凡是大于 x 的元素依次右移一位，遇到第一个不大于 x 的位置即插入点，腾出的空位写入 x。比较与移动合并在同一趟内完成，不必先查找再统一移动。

void Insert(SqList &L, ElemType x) {
int i = L.length - 1;
while (i >= 0 && L.data[i] > x) { // 大于x者后移
L.data[i + 1] = L.data[i];
i--;
}
L.data[i + 1] = x; // 插入
L.length++;
}

void Common(int A[], int B[], int C[], int n) {

if (A[m1] == B[m2]) return A[m1];
if (A[m1] < B[m2]) { // 舍A左半、B右半
if ((s1 + e1) % 2 == 0) s1 = m1; else s1 = m1 + 1;

if ((s2 + e2) % 2 == 0) s2 = m2; else s2 = m2 + 1;

long dist(int a, int b, int c) {
int mx = a, mn = a;
if (b > mx) mx = b; if (b < mn) mn = b;
if (c > mx) mx = c; if (c < mn) mn = c;
return 2L * (mx - mn); // D=2*(max-min)
}
long MinDist(int S1[], int n1, int S2[], int n2, int S3[], int n3) {
long best = dist(S1[0], S2[0], S3[0]);

while (i < n1 && j < n2 && k < n3) {
long d = dist(S1[i], S2[j], S3[k]);
if (d < best) best = d;

else if (S2[j] <= S1[i] && S2[j] <= S3[k]) j++;

}

}

LNode *p = L->next, *pre = L, *q;
while (p != NULL) {
if (p->data == x) { // 删除p
q = p; p = p->next;
pre->next = p; free(q);
} else { // 同步后移
pre = p; p = p->next;
}
}
}

另解：尾插法——令 r 指向已保留链的尾，扫描到的非 x 结点接在 r 后，x 结点直接释放，一遍完成。复杂度：两法均只扫描一趟，时间 O(n)、空间 O(1)。验算：L=(1,2,2,3,2)，x=2：依次删去三个结点，得 (1,3)，头指针链完好。

查看解答

s->data = pa->data;

if (A[i] < mn) mn = A[i];

res[i] = c1 > c2 ? c1 : c2; // 取较大者
}
