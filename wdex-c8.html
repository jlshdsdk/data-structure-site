8.1 · 第2题选择

排序算法的稳定性是指（）

A. 经过排序后，能使关键字相同的元素保持原顺序中的相对位置不变
B. 经过排序后，能使关键字相同的元素保持原顺序中的绝对位置不变
C. 排序算法的性能与被排序元素个数关系不大
D. 排序算法的性能与被排序元素的个数关系密切
查看解析与答案

【解析】

独立验算：选A。稳定性的定义：若排序前Ki=Kj（i<j），排序后两者的相对先后次序不变，则该算法稳定。注意是相对位置而非绝对位置（B错，元素整体移动会改变绝对下标）。C、D谈的是性能与规模的关系，与稳定性无关。

✅ 答案：A　📖 王道书解析 P333

8.1 · 第3题选择

下列关于排序的叙述中，正确的是（）

A. 稳定的排序方法优于不稳定的排序方法
B. 对同一线性表使用不同的排序方法进行排序，得到的排序结果可能不同
C. 排序方法都是在顺序表上实现的，在链表上无法实现排序方法
D. 在顺序表上实现的排序方法在链表上也可以实现
查看解析与答案

【解析】

独立验算：选B。当序列中存在关键字相同的元素时，稳定算法与不稳定算法给出的相对次序可能不同，故不同方法的结果可能不同，B正确。A错：稳定性无优劣之分，只是性质。C错：插入、冒泡、选择、归并等均可在链表上实现。D错：希尔排序、堆排序依赖随机存取（按序号1~i、2i定位），无法直接移植到链表。

✅ 答案：B　📖 王道书解析 P333

8.2 · 综合第2题综合

给出关键字序列{50,26,38,80,70,90,8,30,40,20}的希尔排序过程（取增量序列为d={5,3,1}，排序结果为从小到大排列）。

查看解答

【解答】

思路：按增量d=5、3、1依次做三趟分组插入排序。

第一趟d=5，分组：(50,90)、(26,8)、(38,30)、(80,40)、(70,20)，组内插入排序后得：50,8,30,40,20,90,26,38,80,70。

第二趟d=3，分组：(50,40,26,70)、(8,20,38)、(30,90,80)，排序后依次为(26,40,50,70)、(8,20,38)、(30,80,90)，得：26,8,30,40,20,80,50,38,90,70。

第三趟d=1，即对全表直接插入排序，得最终结果：8,20,26,30,38,40,50,70,80,90。

验算：每趟结束后各分组内均递增（如d=3趟后位置1,4,7,10为26,40,50,70），末趟全表有序，过程正确。

8.2 · 第3题选择·多选重建题

A. n-1
B. n+1
C. n/2
D. n(n-1)/2
查看解析与答案

【解析】

独立验算：最坏选D、最好选A（组合为AD）。最好情况（正序）：每个元素只需与前方紧邻的已排序末元素比较1次即就位，共n-1次，选A。最坏情况（逆序）：第i个元素要与前面i-1个元素全部比较并移动，共1+2+…+(n-1)=n(n-1)/2次，选D。B、C无对应情形。

void OddBeforeEven(int a[], int n){ int i=1, j=n, t; while(i<j){ while(i<j && a[i]%2==1) i++; //i右移越过奇数 while(i<j && a[j]%2==0) j--; //j左移越过偶数 if(i<j){ t=a[i]; a[i]=a[j]; a[j]=t; } } }

试编写一个算法，使之能够在数组L[1...n]中找出第k小的元素（从小到大排序后处于第k个位置的元素）。

查看解答

【解答】

思路：利用快速排序的划分操作：每趟划分把枢轴放到最终位置pos，若pos==k则即为所求；pos>k在左半区间继续划分，pos<k在右半区间继续。这种算法称为快速选择。

int kth(int L[], int low, int high, int k){ int pivot=L[low], i=low, j=high; while(i<j){ while(i<j && L[j]>=pivot) j--; L[i]=L[j]; while(i<j && L[i]<=pivot) i++; L[j]=L[i]; } L[i]=pivot; if(i==k) return L[i]; else if(i>k) return kth(L,low,i-1,k); else return kth(L,i+1,high,k); }

复杂度：平均情况每次只需处理一个子区间，期望比较次数为n+n/2+n/4+…≈2n，平均时间O(n)，空间为递归栈O(log₂n)；最坏（划分总不平衡）退化为O(n²)。相比先完全排序O(nlog₂n)再取第k个更高效。

8.4 · 综合第1题综合

指出堆和二叉排序树的区别。

查看解答

【解答】

二者的区别主要有四点：

(1)结构约束不同：堆必须是完全二叉树；二叉排序树（BST）可以是任意形态的二叉树。

(2)结点间的序关系不同：堆只约束父结点与孩子之间的大小关系（大根堆父≥子、小根堆父≤子），左右子树之间无大小约束；BST约束左子树<根<右子树（对全部后代成立），中序遍历得到递增序列，而堆的中序遍历无序。

(3)用途不同：堆用于堆排序、优先队列，方便取当前最大/最小值；BST用于动态查找，查找、插入、删除平均O(log₂n)。

(4)查找性能不同：在堆中查找任意给定关键字只能顺序扫描，O(n)；在平衡的BST中查找为O(log₂n)。
