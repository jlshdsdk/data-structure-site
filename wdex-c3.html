3.1 · 第1题选择

栈和队列具有相同的（）

A. 抽象数据类型
B. 逻辑结构
C. 存储结构
D. 运算
查看解析与答案

【解析】

独立验算：选B。栈和队列都是线性结构，元素之间均为一对一关系，逻辑结构相同；二者差别在于运算的限定：栈只允许在栈顶进出（LIFO），队列只允许队尾入、队头出（FIFO），故D不同。存储结构顺序、链式均可任选，C不对；抽象数据类型=逻辑结构+运算，运算不同则ADT不同，A不对。

✅ 答案：B　📖 王道书解析 P69

3.1 · 综合第1题综合

有5个元素，其入栈次序为A、B、C、D、E，在各种可能的出栈次序中，第一个出栈元素为C且第二个出栈元素为D的出栈序列有哪几个？

查看解答

【解答】

思路：第一个出栈为C，说明A、B已入栈（B压在A上）；第二个出栈为D，说明D一入栈立即出栈。此后栈内仅剩A、B且只能按B、A顺序出栈，E可在任意时刻入栈穿插。

枚举：C、D出栈后，剩余B、A在栈中、E未入栈，可能的后续操作只有“何时让E入栈出栈”三种：

① E先入即出，再B、A出：C D E B A；
② B先出，E入即出，A出：C D B E A；
③ B、A出完，E入即出：C D B A E。

结论：满足条件的出栈序列共3个：CDEBA、CDBEA、CDBAE。（验算：每种序列均可写出一组合法的S/X操作序列，如CDEBA对应的操作序列为SSSX SX SX XX，即A、B、C入栈，C出栈，D入即出，E入即出，B、A再出栈，逐步合法。）

3.1 · 综合第2题综合

若元素的进栈序列为A、B、C、D、E，运用栈操作，能否得到出栈序列BCAED和DBACE？为什么？

查看解答

【解答】

思路：判断一个序列是否为合法出栈序列，用模拟法：按给定出栈目标，逐个把进栈序列元素入栈，栈顶等于目标就弹出；若元素耗尽而栈顶不匹配则不合法。

序列BCAED：操作为A入、B入、B出、C入、C出、A出、D入、E入、E出、D出，每步合法，得到BCAED，可能。

序列DBACE：D第一个出栈要求A、B、C先全部入栈，此时栈内自顶向下为C、B、A；D入即出后，下一个输出目标是B，但栈顶是C，B被C压住无法先出，矛盾，故不可能。

结论：BCAED可以得到；DBACE得不到，原因是D先出栈迫使A、B、C全入栈，破坏了“B先于C出栈”的要求。

3.1 · 综合第3题综合

栈的初态和终态均为空，以I和O分别表示入栈和出栈操作，则出入栈的操作序列可表示为由I和O组成的序列，可以操作的序列称为合法序列，否则称为非法序列。

(1) 对给定的若干I/O序列，如何判定哪些是合法的？
(2) 通过对(1)的分析，写出一个算法，判定所给的操作序列是否合法。若合法，返回true，否则返回false（假定被判定的操作序列已存入一维数组中）。【第(1)问的具体序列图OCR缺失，按王道原题以判定规则补全】

查看解答

【解答】

(1) 判定规则：操作序列合法当且仅当：①任意前缀中O的个数不超过I的个数（栈空不能再出栈）；②整个序列中I与O的个数相等（终态为空）。例如IOIIOIOO合法；IOOIOIIO第3个字符前O已有2个而I只有1个，非法；OOIOIIOI第1个字符即出栈，非法。

(2) 算法（计数法）：设数组a[0..n-1]存放操作序列，用cnt记录栈中元素个数：遇I加1，遇O减1；一旦cnt<0立即返回false；扫描结束后cnt==0则合法。

bool Judge(char a[], int n) {
  int cnt = 0;  // 栈中元素计数
  for (int i = 0; i < n; i++) {
    if (a[i] == 'I') cnt++;
    else {
      cnt--;
      if (cnt < 0) return false; // 空栈出栈，非法
    }
  }
  return (cnt == 0); // 终态须为空
}

时间复杂度O(n)，空间复杂度O(1)。双验算：对IOIIOIOO模拟cnt依次为1,0,1,2,1,2,1,0，无负值且终值0，返回true，与规则一致。

3.1 · 综合第4题综合

设单链表的表头指针为L，结点结构由data和next两个域构成，其中data域为字符型。试设计算法判断该链表的全部n个字符是否中心对称。例如xyx、xyyx都是中心对称。

查看解答

【解答】

思路：利用栈的后进先出特性：把链表前半部分（⌊n/2⌋个字符）依次入栈，然后扫描后半部分，每走一步与出栈字符比较；若全部相等则中心对称。n为奇数时中间字符自然跳过（不入栈不比较）。

bool dc(LinkList L, int n) {
  char S[n/2]; int top = -1; // 顺序栈存前半
  LNode *p = L->next;
  for (int i = 0; i < n/2; i++) { // 前半入栈
    S[++top] = p->data; p = p->next;
  }
  if (n % 2 == 1) p = p->next; // 奇数跳过中点
  while (p != NULL) {  // 后半与出栈比较
    if (p->data != S[top--]) return false;
    p = p->next;
  }
  return true;
}

验算：xyy x（n=4）：“xy”入栈后p指向y，y==S[top]=y、x==S[top]=x，返回true；abc（n=3）：a入栈，跳过b，c≠a返回false，均正确。时间复杂度O(n)，空间复杂度O(n/2)=O(n)。

若希望循环队列中的元素都能得到利用，则需设置一个标志域tag，并以tag的值为0或1来区分队头指针front和队尾指针rear相同时的队列状态是“空”还是“满”。试编写与此结构相应的入队和出队算法。

查看解答

【解答】

思路：队列类型含数组data[MaxSize]、front、rear和tag。约定front指向队首元素的前一个位置、rear指向队尾元素，入队先移rear再存，出队先移front再取。tag=0表示空、1表示满；仅当front==rear时才看tag判空满。

typedef struct {
  ElemType data[MaxSize];
  int front, rear, tag;
} Queue;

bool EnQueue(Queue &Q, ElemType x) {
  if (Q.front == Q.rear && Q.tag == 1) return false; // 队满
  Q.rear = (Q.rear + 1) % MaxSize;
  Q.data[Q.rear] = x;
  if (Q.front == Q.rear) Q.tag = 1; // 入队后重合则满
  return true;
}

bool DeQueue(Queue &Q, ElemType &x) {
  if (Q.front == Q.rear && Q.tag == 0) return false; // 队空
  Q.front = (Q.front + 1) % MaxSize;
  x = Q.data[Q.front];
  if (Q.front == Q.rear) Q.tag = 0; // 出队后重合则空
  return true;
}

验算：设MaxSize=3，依次入a、b、c后rear绕回与front重合、tag置1（满，3个元素全部利用）；出队a、b、c后front追上rear、tag置0（空），与预期一致。两算法均为O(1)。

  ElemType x;

  while (!StackEmpty(S)) { // S弹回Q
    Pop(S, x); EnQueue(Q, x);

#define maxsize 100
typedef struct {
  ElemType data[maxsize];
  int top1 = -1, top2 = maxsize;
} DStack;

bool Push(DStack &s, int i, ElemType x) { // i=1或2
  if (s.top1 + 1 == s.top2) return false; // 共享空间满
  if (i == 1) s.data[++s.top1] = x;
  else        s.data[--s.top2] = x;
  return true;
}

bool Pop(DStack &s, int i, ElemType &x) {
  if (i == 1) {
    if (s.top1 == -1) return false;  // 栈1空
    x = s.data[s.top1--];
  } else {
    if (s.top2 == maxsize) return false; // 栈2空
    x = s.data[s.top2++];
  }
  return true;
}

bool Match(char exp[]) { // exp以'0'结尾
  char S[MaxSize]; int top = -1, i = 0;
  while (exp[i] != '0') {
    char c = exp[i];
    if (c=='(' || c=='[' || c=='{') S[++top] = c; // 入栈
    else if (c==')' || c==']' || c=='}') {
      if (top == -1) return false;    // 右括号多余
      char t = S[top--];
      if ((c==')' && t!='(') || (c==']' && t!='[')
       || (c=='}' && t!='{')) return false; // 类型不符
    }
    i++;
  }
  return (top == -1); // 有剩余左括号则不配对
}

双验算："(a[b]{c})0"：入(、[、]，弹]对[、}对{、)对(，结束栈空，返回true；"(a[b)0"：弹)时栈顶为[，类型不符返回false；"a[b0"：结束符时栈中剩[，返回false。三种情况均正确。时间复杂度O(n)。

(3) 画出第一个元素入队后的队列状态。
(4) 给出入队操作和出队操作的基本过程。

查看解答

【解答】

(1) 应选择链式存储结构。理由：要求入队时能增加占用空间且入队、出队始终保持O(1)——顺序存储容量固定，扩容需整体搬迁，无法满足；采用带头结点的循环单链表并只设一个尾指针rear，入队时动态申请新结点（或复用出队留下的空闲结点），出队结点不释放而挂回链上，恰好实现“空间只增不减、可重复使用”。

(2) 初始状态：只有头结点，rear指向头结点。

初始： rear → [头结点] ⇂ (空)
队空条件：rear->next == rear（尾指针指向自身/头结点）
链式队列无固定容量，一般不判队满（仅当内存申请失败视为满）

(3) 第一个元素a1入队后：

  [头结点] → [a1] ⇂
  rear 指向 a1，头结点自指被打破：rear->next = a1结点

(4) 入队EnQueue(x)：申请新结点s（若出队留有空闲结点则直接复用），插入rear之后：s->next=rear->next; rear->next=s; rear=s；若原队空则rear=s。出队DeQueue(x)：p=rear->next（头结点），取q=p->next（队首），x=q->data；p->next=q->next；若删后队空（即被删结点恰是rear所指的唯一元素结点，p->next==rear）则令rear=p重新指向头结点；结点q挂回链上备用或释放（题目要求空间可重复使用，则回挂）。两个操作均只做有限次指针修改，时间复杂度均为O(1)。

对特殊矩阵采用压缩存储的主要目的是（）

A. 使表达变得简单
B. 对矩阵元素的存取变得简单
C. 去掉矩阵中的多余元素
D. 减少不必要的存储空间
查看解析与答案

【解析】

独立验算：选D。对称矩阵、三角矩阵、对角矩阵中存在大量值相同（可映射到同一单元）或恒为0的元素，压缩存储只为其中“有效”元素分配空间，主要目的就是节省存储空间。它反而使存取需要换算下标（B错），与表达是否简单无关（A错），相同元素并非“多余”元素而是必要信息（C错）。

✅ 答案：D　📖 王道书解析 P104

对n阶对称矩阵压缩存储时，需要表长为（）的顺序表。

A. n/2
B. n×n/2
C. n(n+1)/2
D. n(n-1)/2
查看解析与答案

【解析】

独立验算：选C。对称矩阵只需存储下三角（含对角线）：第1行1个、第2行2个、…、第n行n个，共1+2+…+n=n(n+1)/2个元素，上三角元素由对称性映射即可。D的n(n-1)/2漏掉对角线；A、B数量级或构成不对。

✅ 答案：C　📖 王道书解析 P105

有一个n×n的对称矩阵A，将其下三角部分按行存放在一维数组B中，而A[0][0]存放于B[0]中，则第i+1行的对角元素A[i][i]存放于B中的（）处。

A. (i+3)i/2
B. (i+1)i/2
C. (2n-i+1)i/2

稀疏矩阵采用压缩存储后的缺点主要是（）
